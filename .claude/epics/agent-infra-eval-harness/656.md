# Task: Model grader implementation (LLM-as-judge)

## Description
Implement the model-based grader that uses an LLM-as-judge to evaluate qualitative fields in agent output: `key_factors`, `summary`, `contrarian_thesis`, and other free-text fields. The grader uses a PydanticAI agent with a rubric prompt to judge whether the qualitative output meets quality standards.

## Acceptance Criteria
- [ ] `ModelGrader` uses a PydanticAI agent with rubric prompt
- [ ] Rubric evaluates: specificity, data citation, actionability, coherence
- [ ] Uses a different LLM provider than debate agents (avoid self-grading)
- [ ] Returns `EvalRun` with pass/fail and reasoning in details
- [ ] `model=None` at init pattern (enables TestModel in tests)
- [ ] Never-raises runner pattern with timeout
- [ ] Tests use `TestModel` — no real API calls

## Technical Details
- New file: `src/options_arena/evals/model_grader.py`
- PydanticAI `Agent[ModelGraderDeps, GraderResult]` with structured output
- `GraderResult` internal model: passed, reasoning, scores per criterion
- Rubric prompt evaluates: are key_factors specific? Do they cite data? Is summary actionable?
- Config: `EvalConfig.model_grader_model` determines which provider to use
