# Task: Eval persistence layer (migration + EvalMixin)

## Description
Create the SQLite persistence layer for eval definitions and eval runs. This includes a new migration (039), an `EvalMixin` for the Repository, and CRUD operations that return typed Pydantic models.

## Acceptance Criteria
- [ ] Migration 039 creates `eval_definitions` and `eval_runs` tables
- [ ] `EvalMixin` with save/query methods for definitions and runs
- [ ] `Repository` class includes `EvalMixin` in its inheritance chain
- [ ] All queries return typed Pydantic models (never raw dicts)
- [ ] `await db.commit()` after every write
- [ ] Named column access via `aiosqlite.Row`
- [ ] Tests use `:memory:` SQLite databases

## Technical Details
- New migration: `data/migrations/039_eval_runs.sql`
- New mixin: `src/options_arena/data/_eval.py`
- Update: `src/options_arena/data/repository.py` (add EvalMixin to inheritance)
- Tables: `eval_definitions` (name PK, eval_type, grader_type, target_desk, fixture_path, expected_direction, expected_confidence_min, expected_confidence_max, description, created_at)
- Tables: `eval_runs` (id INTEGER PK AUTOINCREMENT, eval_name FK, timestamp, passed, attempts, successes, model_used, duration_ms, details TEXT, created_at)
