# Task: Render Integration — Confidence-Weighted Pattern Injection

## Description
Update `render_learned_patterns()` in `learning/strategy_book.py` to leverage the new `confidence` field on `StrategyRule`. Rules are sorted by confidence descending, high-confidence rules get stronger language, low-confidence rules appear as caveats, and rules below 0.3 confidence are excluded entirely from injection.

## Acceptance Criteria
- [ ] `render_learned_patterns()` filters out rules with `confidence < 0.3`
- [ ] Remaining rules sorted by `confidence` descending (highest confidence first)
- [ ] High-confidence rules (>= 0.8) rendered with stronger language: "Strong pattern:"
- [ ] Medium-confidence rules (0.3-0.8) rendered with: "Pattern:"
- [ ] Confidence score included in output: `(confidence: {conf:.0%})`
- [ ] Existing tests updated to account for new rendering format
- [ ] Empty string returned when no approved rules remain after confidence filtering

## Technical Details
- File: `src/options_arena/learning/strategy_book.py`, function `render_learned_patterns()`
- Currently filters on `status == APPROVED` only — add `confidence >= 0.3` filter
- Currently renders each rule as: `Pattern: {rule.pattern}`, `Win Rate: ...`, `Avg Return: ...`
- New rendering adds confidence tier language and confidence percentage
- Sort order changes from implicit (insertion order) to explicit (confidence DESC)
- Truncation logic remains the same (MAX_PATTERN_TEXT_CHARS with pattern-boundary cutoff)

## Execution

### Read First
Files that MUST be read before starting this task:

- `tests/unit/learning/test_strategy_book.py` — existing tests for this function
- `src/options_arena/models/strategy.py` — StrategyRule model with new confidence field

### Action
1. In `render_learned_patterns()`, update the filter to include confidence:
   - `approved = [r for r in rules if r.status == RuleStatus.APPROVED and r.confidence >= 0.3]`
   - WHY: exclude low-confidence rules from prompt injection per epic spec
2. Sort approved rules by confidence descending:
   - `approved.sort(key=lambda r: r.confidence, reverse=True)`
   - WHY: highest-confidence patterns appear first in prompt
3. Update the rendering loop to use confidence-tiered language:
   - `>= 0.8`: `"Strong pattern: {rule.pattern} (confidence: {rule.confidence:.0%})"`
   - `< 0.8`: `"Pattern: {rule.pattern} (confidence: {rule.confidence:.0%})"`
   - WHY: confidence-weighted prompt injection per architecture decision
4. Keep `Win Rate:` and `Avg Return:` lines unchanged
5. Update existing tests in `test_strategy_book.py` to pass new confidence field to test rules
   - WHY: backward compatibility — existing tests need updated fixtures
