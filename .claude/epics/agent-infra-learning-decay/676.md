# Task: CLI Enhancement — Playbook Confidence Display and Decay Command

## Description
Enhance the `learn playbook` CLI command to display confidence scores and last validation dates. Add a new `learn decay` command for manual decay triggering. Hook `run_confidence_decay()` into the `outcomes collect` flow so decay runs automatically after outcome collection.

## Acceptance Criteria
- [ ] `learn playbook` table includes "Confidence" and "Last Validated" columns
- [ ] Confidence displayed as percentage (e.g., "85%"), last_validated as date or "--"
- [ ] `learn decay` command triggers `run_confidence_decay()` manually
- [ ] `learn decay` displays summary: rules processed, promoted, demoted
- [ ] `outcomes collect` calls `run_confidence_decay()` after collecting outcomes
- [ ] All CLI commands are sync wrappers with `asyncio.run()`

## Technical Details
- File: `src/options_arena/cli/agency.py` — `learn_playbook` and new `learn_decay` commands
- File: `src/options_arena/cli/outcomes.py` — hook decay into `_outcomes_collect_async`
- Current `learn playbook` table has columns: Rule ID, Pattern, Win Rate, Avg Return, Samples, Status
- Add 2 new columns: Confidence (right-aligned, percentage), Last Validated (right-aligned, date or "--")
- New `learn decay` command: no required args, creates DB connection, calls `run_confidence_decay()`
- Outcomes integration: after `OutcomeCollector.collect()` completes, call `run_confidence_decay(repo)`
- CLI pattern: sync Typer command + `asyncio.run()` (per cli/CLAUDE.md)

## Execution

### Read First
Files that MUST be read before starting this task:
- `src/options_arena/cli/agency.py` — current `learn_playbook` and other learn commands
- `src/options_arena/cli/outcomes.py` — `_outcomes_collect_async` for decay hook
- `src/options_arena/learning/confidence_decay.py` — `run_confidence_decay()` API (from Task 003)
- `src/options_arena/cli/CLAUDE.md` — CLI patterns and rules

### Action
1. In `cli/agency.py`, update `_learn_playbook_async()` to add confidence columns to the table:
   - Add column: `table.add_column("Confidence", justify="right")`
   - Add column: `table.add_column("Last Validated", justify="right")`
   - In row rendering: `f"{r.confidence:.0%}"` for confidence, `r.last_validated.strftime('%Y-%m-%d') if r.last_validated else "--"` for date
   - WHY: users need visibility into rule confidence for informed approval decisions
2. Add `learn_decay` command to `learn_app`:
   - Sync Typer command wrapping `_learn_decay_async()`
   - Async function: open DB, call `run_confidence_decay(repo)`, display summary
   - Summary table: "Rules processed", "Rules promoted", "Rules demoted"
   - WHY: admin/testing ability to manually trigger decay
3. In `cli/outcomes.py`, add decay hook after outcome collection:
   - After `collector.collect()` returns, call `await run_confidence_decay(repo)`
   - Import `run_confidence_decay` from `options_arena.learning`
   - Wrap in try/except to not fail outcomes collection on decay error
   - WHY: decay is outcome-triggered per architecture decision
4. Import `run_confidence_decay` from `options_arena.learning` in both files
   - WHY: public API from learning module
