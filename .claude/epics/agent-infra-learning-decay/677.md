# Task: Rules-Distill Development Skill

## Description
Create a `.claude/prompts/rules-distill.md` development skill that extracts cross-cutting principles from agent prompts and solution documents, identifies patterns appearing in 2+ sources, and assists in appending validated rules to `.claude/rules/`. This is a dev-time artifact, not production code.

## Acceptance Criteria
- [ ] `.claude/prompts/rules-distill.md` created with 3-phase workflow
- [ ] Phase 1: Glob prompt files + solution docs to identify source material
- [ ] Phase 2: Cross-read and identify principles appearing in 2+ sources
- [ ] Phase 3: Present findings for user approval, append to `.claude/rules/`
- [ ] Skill can be invoked via `/rules-distill` slash command
- [ ] Output format matches existing `.claude/rules/` file conventions
