### `ToolResponse[T]` (`models/tool_response.py` — NEW FILE)
```python
from __future__ import annotations

from typing import Generic, TypeVar

from pydantic import BaseModel, ConfigDict, Field

from options_arena.models.enums import ToolStatus

T = TypeVar("T")

class ToolResponse(BaseModel, Generic[T]):
    model_config = ConfigDict(frozen=True)

    status: ToolStatus
    summary: str
    data: T | None = None
    next_actions: list[str] = Field(default_factory=list)
```

This is the first `Generic[T]` Pydantic model in the project. Pydantic v2 natively
supports generics — no special configuration needed.

### `_sanitize_error()` helper (`agents/_toolsets.py`)
```python
def _sanitize_error(exc: Exception, max_len: int = 120) -> str:
    """Extract a safe, truncated error message from an exception."""
    msg = str(exc)
    # Strip potential credential leaks (API keys, tokens)
    msg = re.sub(r"(key|token|secret|password)=\S+", r"\1=***", msg, flags=re.IGNORECASE)
    if len(msg) > max_len:
        msg = msg[:max_len] + "..."
    return msg
```
Add `import re` at the top of `_toolsets.py` (if not already present).
