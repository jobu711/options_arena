# Task: Refactor market data tools to ToolResponse

## Description

Refactor the 5 market data tool functions in `agents/_toolsets.py` to return
`ToolResponse` JSON instead of raw formatted strings. Each tool wraps its success
and error paths in `ToolResponse` with tool-specific `next_actions` guidance.

## Acceptance Criteria

- [ ] `fetch_quote` returns ToolResponse JSON on success, error, and validation paths
- [ ] `fetch_vol_surface_slice` returns ToolResponse JSON on all paths
- [ ] `compute_iv_for_strike` returns ToolResponse JSON on all paths
- [ ] `fetch_correlation` returns ToolResponse JSON on all paths (including partial data WARNING)
- [ ] `fetch_related_ohlcv` returns ToolResponse JSON on all paths
- [ ] All 5 tools preserve `ctx.deps.tools_used.append()` on every path
- [ ] Return type remains `str` (no signature change)
- [ ] Existing toolset tests still pass (updated for JSON output)

## Technical Details

### Tools to Refactor (5 functions)

1. **`fetch_quote`** (~30 lines)
   - SUCCESS: price, bid/ask, volume, 52W range
   - WARNING: quote fetched but 52W range unavailable (inner try/except)
   - ERROR: quote fetch failed
   - `next_actions` SUCCESS: `["assess price vs 52W range", "note bid-ask spread width"]`
   - `next_actions` WARNING: `["assess price action without range context"]`
   - `next_actions` ERROR: `["skip price analysis", "reduce confidence by 0.1"]`

2. **`fetch_vol_surface_slice`** (~40 lines)
   - SUCCESS: IV by strike/expiry for up to 10 contracts
   - WARNING: fewer contracts than expected
   - ERROR: chain fetch failed
   - `next_actions` SUCCESS: `["compare IV across strikes", "identify skew direction"]`
   - `next_actions` ERROR: `["use context IV data only", "note vol surface unavailable"]`

3. **`compute_iv_for_strike`** (~35 lines)
   - SUCCESS: IV details for closest strike
   - ERROR: computation or data fetch failed
   - `next_actions` SUCCESS: `["compare market IV to model IV", "assess moneyness"]`
   - `next_actions` ERROR: `["skip strike-level IV analysis", "use aggregate IV only"]`

4. **`fetch_correlation`** (~40 lines)
   - SUCCESS: pairwise correlations for all requested tickers
   - WARNING: some tickers had insufficient data (partial results)
   - ERROR: no correlations computed
   - `next_actions` SUCCESS: `["assess diversification benefit", "flag high correlations"]`
   - `next_actions` WARNING: `["note incomplete correlation data", "assess available pairs only"]`
   - `next_actions` ERROR: `["skip correlation analysis", "note data gap"]`

5. **`fetch_related_ohlcv`** (~25 lines)
   - SUCCESS: last 5 OHLCV bars
   - ERROR: fetch failed
   - `next_actions` SUCCESS: `["assess recent price action", "note volume trends"]`
   - `next_actions` ERROR: `["skip recent price analysis", "rely on context data"]`

### Refactoring Pattern
```python
# BEFORE
async def fetch_quote(ctx: RunContext[DeskDeps], ticker: str) -> str:
    tool_name = "fetch_quote"
    if err := _validate_ticker(ticker):
        ctx.deps.tools_used.append(tool_name)
        return err
    try:
        quote = await ctx.deps.market_data.fetch_quote(ticker)
        lines = [...]
        ctx.deps.tools_used.append(tool_name)
        return "\n".join(lines)
    except Exception as exc:
        logger.debug("fetch_quote failed for %s: %s", ticker, exc)
        ctx.deps.tools_used.append(tool_name)
        return f"Error: could not fetch quote for {ticker}"

# AFTER
async def fetch_quote(ctx: RunContext[DeskDeps], ticker: str) -> str:
    tool_name = "fetch_quote"
    if err := _validate_ticker(ticker):
        ctx.deps.tools_used.append(tool_name)
        return ToolResponse[str](
            status=ToolStatus.ERROR,
            summary=err,
            next_actions=["skip price analysis", "reduce confidence by 0.1"],
        ).model_dump_json()
    try:
        quote = await ctx.deps.market_data.fetch_quote(ticker)
        lines = [...]
        ctx.deps.tools_used.append(tool_name)
        return ToolResponse[str](
            status=ToolStatus.SUCCESS,
            summary=f"{ticker}: ${quote.price} bid={quote.bid} ask={quote.ask}",
            data="\n".join(lines),
            next_actions=["assess price vs 52W range", "note bid-ask spread width"],
        ).model_dump_json()
    except Exception as exc:
        logger.debug("fetch_quote failed for %s: %s", ticker, exc)
        ctx.deps.tools_used.append(tool_name)
        return ToolResponse[str](
            status=ToolStatus.ERROR,
            summary=f"Quote unavailable for {ticker}: {_sanitize_error(exc)}",
            next_actions=["skip price analysis", "reduce confidence by 0.1"],
        ).model_dump_json()
```
