# Task: Update recommendation prompts with ToolResponse format section

## Description

Add a "Tool Response Format" section to all 6 recommendation prompts and the
synthesis prompt, explaining the ToolResponse JSON structure and how agents should
interpret `status` and `next_actions` when tool results indicate partial or missing
data. Keep the section brief (~200-300 chars) to stay within the <8000 char prompt
budget.

## Acceptance Criteria

- [ ] All 6 `recommend_*.py` prompts have a "Tool Response Format" section
- [ ] `synthesis.py` prompt has a "Tool Response Format" section
- [ ] Each section explains status (success/warning/error) and next_actions
- [ ] Each prompt stays under 8000 chars total
- [ ] Tests verify the section is present in each prompt
- [ ] Tests verify prompt char length constraint

## Technical Details

### Section to Add (identical across all 7 prompts)

Insert before the `PROMPT_RULES_APPENDIX` concatenation:

```python
TOOL_RESPONSE_FORMAT = """
## Tool Response Format
Tools return JSON: {"status": "success|warning|error", "summary": "...", "data": ..., "next_actions": [...]}
- **success**: Data is complete. Use the data and summary for your analysis.
- **warning**: Partial data available. Follow next_actions to adjust your assessment scope.
- **error**: Data unavailable. Follow next_actions to handle the gap (reduce confidence, note limitation).
Always check the status field before using tool output. Never ignore next_actions on warning/error.
"""
```
