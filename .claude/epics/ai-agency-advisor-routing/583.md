# Task: API Endpoints + CLI Commands for Agency

## Description

Wire the agency system into both the FastAPI REST API and the Typer CLI. This task
creates API routes for submitting queries, retrieving responses, and listing query
history, plus a CLI `agency` subcommand group for terminal-based interaction. Both
entry points delegate to `run_agency_query()` from task 581 and persist via the
`AgencyMixin` from task 582.

API routes follow existing patterns in `api/routes/` (async handlers, `Depends()` DI,
Pydantic response models). CLI follows existing patterns in `cli/` (sync Typer commands
wrapping `asyncio.run()`, Rich output). Agency queries share the operation mutex lock
(409 if a scan or batch debate is already running).

### CLI Design (`cli/agency.py`)

```python
import asyncio
import typer
from rich.console import Console
from rich.table import Table
from rich.panel import Panel

agency_app = typer.Typer(name="agency", help="AI agency desk queries.")

@agency_app.command("ask")
def ask(
    query: str = typer.Argument(..., help="Natural language question"),
    desk: str | None = typer.Option(None, "--desk", "-d", help="Target desk"),
    ticker: str | None = typer.Option(None, "--ticker", "-t", help="Ticker symbol"),
) -> None:
    """Submit a query to the AI agency."""
    asyncio.run(_ask_async(query, desk, ticker))

@agency_app.command("history")
def history(
    limit: int = typer.Option(20, "--limit", "-n", help="Number of queries"),
) -> None:
    """Show recent agency queries."""
    asyncio.run(_history_async(limit))
```

### Key Patterns
- **Operation mutex**: API route acquires `app.state.operation_lock` with non-blocking `acquire()`. If lock is held, raise `HTTPException(409)`. Release in `finally`.
- **Service access (API)**: Services from `app.state` via `Depends()` providers already in `deps.py` (market_data, options_data, fred, repo).
- **Service access (CLI)**: `_ask_async()` creates services locally (same pattern as `_scan_async()` in `cli/commands.py`), closes in `finally`.
- **Model builder**: `build_debate_model(config)` from `agents/model_config.py` for desk agent model.
- **Synchronous execution**: Agency queries run synchronously in the request handler (not background tasks). They are fast (<30s) and the caller needs the response immediately.
- **No WebSocket for V1**: Queries are short-lived. WebSocket streaming can be added later.
- **Rich output**: CLI renders response as a `Panel` with desk attribution, confidence percentage, tools used as comma-separated list, and the response text.

### Edge Cases
- Empty query string: API returns 422 validation error
- Unknown desk type: API returns 422 (Pydantic validates DeskType enum)
- Invalid query_id (negative, non-integer): API returns 422
- Query not found: API returns 404
- Operation lock held by scan: API returns 409
- Operation lock held by batch debate: API returns 409
- Service initialization failure in CLI: error message with guidance
- Very long query string: accepted (no length limit in V1)

### Mocking Strategy
- **API tests**: Use `httpx.AsyncClient` with FastAPI `TestClient` pattern. Mock `run_agency_query()` to return synthetic `AgencyResponse`. Mock `repo.get_agency_query()` and `repo.list_agency_queries()` for GET endpoints. Mock `operation_lock` state for 409 tests.
- **CLI tests**: Use `typer.testing.CliRunner`. Mock `_ask_async()` and `_history_async()` or mock the underlying `run_agency_query()` and repo calls. Capture stdout for Rich output verification.
