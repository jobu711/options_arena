# Task: AgencyChat.vue Frontend Component

## Description

Build the Vue 3 frontend for the agency system: a chat-style interface where users can
submit natural language queries, optionally select a target desk, and view agent
responses with desk attribution, tool usage badges, confidence indicators, and citation
display. Includes a Pinia store for state management, an API client module, Vue Router
integration, and navigation link.

This is the user-facing completion of the agency pipeline. The API endpoints from task
583 must exist before this task can be implemented.

### API Client (`web/src/api/agency.ts`)

```typescript
import { api } from './client'

export interface AgencyQueryRequest {
  query: string
  desk?: string | null
  tickers?: string[] | null
}

export interface AgencyResponse {
  query_id: number
  query_text: string
  desk_responses: DeskResponseSummary[]
  synthesis: string
  citations: string[]
  confidence: number
  tools_used: string[]
  created_at: string
}

export interface DeskResponseSummary {
  desk: string
  response: string
  confidence: number
  tools_used: string[]
}

export async function submitAgencyQuery(request: AgencyQueryRequest): Promise<AgencyResponse> {
  const { data } = await api.post('/api/agency/query', request)
  return data
}

export async function getAgencyQuery(queryId: number): Promise<AgencyResponse> {
  const { data } = await api.get(`/api/agency/query/${queryId}`)
  return data
}

export async function listAgencyQueries(limit: number = 20): Promise<AgencyResponse[]> {
  const { data } = await api.get('/api/agency/queries', { params: { limit } })
  return data
}
```

### Pinia Store (`web/src/stores/agency.ts`)

```typescript
import { defineStore } from 'pinia'
import { ref } from 'vue'
import type { AgencyResponse, AgencyQueryRequest } from '@/api/agency'
import { submitAgencyQuery, listAgencyQueries } from '@/api/agency'

export const useAgencyStore = defineStore('agency', () => {
  const messages = ref<AgencyResponse[]>([])
  const loading = ref(false)
  const error = ref<string | null>(null)

  async function submitQuery(request: AgencyQueryRequest): Promise<void> {
    loading.value = true
    error.value = null
    try {
      const response = await submitAgencyQuery(request)
      messages.value.unshift(response)
    } catch (e: unknown) {
      // Handle 409 specially — "Analysis in progress"
      // Handle other errors with generic message
      error.value = extractErrorMessage(e)
    } finally {
      loading.value = false
    }
  }

  async function loadHistory(limit: number = 20): Promise<void> {
    try {
      messages.value = await listAgencyQueries(limit)
    } catch (e: unknown) {
      error.value = extractErrorMessage(e)
    }
  }

  return { messages, loading, error, submitQuery, loadHistory }
})
```

### Edge Cases
- Empty query submission: button disabled or validation message
- Very long query text: input accepts, layout does not break
- API returns 409 (busy): user-friendly "Analysis in progress" message
- API returns 500: generic error message with retry suggestion
- No query history: empty state with prompt to ask first question
- Rapid successive submissions: loading state prevents double-submit
- Network offline: error handling shows connection message

### Mocking Strategy
- **E2E tests**: Use Playwright route interception (`page.route()`) to mock API responses for deterministic tests. Intercept `POST /api/agency/query` and `GET /api/agency/queries` with fixture data.
- **No Vitest unit tests**: Project convention uses E2E only for frontend testing.
