# Task: Fundamental + Contrarian Desk Agents with Tools, Prompts, and Unit Tests

## Description

Build the Fundamental and Contrarian desk agents following the Epic 1 pattern. Fundamental desk gets 3 base tools (standard budget). Contrarian is deliberately tool-light (2 tools, budget 2) — it debates prior analysis rather than running its own computations. Each desk gets tool wrappers, agent module, prompt file, and unit tests.

## Technical Details

### Tool Implementations

**`fetch_earnings_history(ctx, ticker)`** — Fundamental desk
- Calls `ctx.deps.market_data.fetch_ticker_info(ticker)` for basic fundamentals
- Calls `ctx.deps.market_data.fetch_earnings_date(ticker)` for next earnings date
- Returns formatted string: sector, industry, P/E, forward P/E, market cap, dividend yield, next earnings date
- Fields from `TickerInfo`: `sector`, `industry`, `pe_ratio`, `forward_pe`, `market_cap`, `dividend_yield`, `fifty_two_week_high`, `fifty_two_week_low`
- Guards None fields with "N/A" display

**`fetch_sector_comparison(ctx, ticker)`** — Fundamental desk
- Fetches ticker info for the primary ticker
- Gets sector from `TickerInfo.sector`
- Returns the ticker's fundamental metrics plus sector context string
- NOTE: Full sector peer comparison requires universe data which may not be available; return single-ticker fundamentals with sector label as V1

**`fetch_debate_history(ctx, ticker, limit=3)`** — Contrarian desk
- Calls `ctx.deps.repo.get_debates_for_ticker(ticker, limit=limit)` — returns `list[DebateRow]`
- Returns formatted string: for each past debate, show date, direction, confidence, summary excerpt
- If no history: "No prior debate history found for {ticker}"
- This is the key tool — Contrarian uses past analysis to argue the opposite case

### Contrarian Tool Budget

Add `contrarian_tool_budget: int = 2` to `AgencyConfig` in `models/config.py` (alongside existing `default_tool_budget` and `risk_tool_budget`). Use `math.isfinite()` validator following existing pattern.

### Desk Agent Pattern

Both follow vol_desk.py exactly. Key difference:
- Fundamental uses `cfg.default_tool_budget` (3)
- Contrarian uses `cfg.contrarian_tool_budget` (2) — deliberately low, forces the agent to reason from minimal data

### Prompt Design

**Fundamental**: Focus on valuation context, earnings proximity, sector comparison. Scope boundary: does NOT give IV analysis or trade recommendations.

**Contrarian**: Unique among desks — prompt emphasizes challenging consensus, finding blind spots, arguing the opposite case. Must reference prior debate history from `fetch_debate_history`. Scope boundary: does NOT run its own computations.
