# Task: Research Desk with Curated Cross-Domain Tools

## Description

Build the Research desk — the generalist desk that curates tools from across all domains. Unlike specialist desks that have domain-scoped tools, Research gets a curated subset of 6 base tools spanning multiple domains, with a tool call budget of 5. This forces the agent to prioritize which tools to call rather than exhausting all options.

- [ ] `agents/prompts/desk_research.py` with `DESK_RESEARCH_PROMPT`
- [ ] Research desk uses `cfg.research_tool_budget` (5) — already exists on `AgencyConfig`
- [ ] Prompt explicitly lists all 6 tools with descriptions
- [ ] Prompt guides tool prioritization given budget of 5
- [ ] Unit tests passing

## Technical Details

### Curated Tool Selection Rationale

The Research desk is not "all tools" — it's a curated subset:

| Tool | Source Desk | Why Included |
|------|-------------|--------------|
| `fetch_quote` | Shared | Every query starts with current price context |
| `fetch_vol_surface_slice` | Volatility | IV context is essential for options analysis |
| `fetch_chain_summary` | Flow (task 001) | Aggregated chain stats for quick overview |
| `fetch_earnings_history` | Fundamental (task 002) | Valuation + earnings proximity |
| `compute_indicator_on_demand` | Trend (task 001) | Technical analysis on demand |
| `fetch_debate_history` | Contrarian (task 002) | Historical perspective from prior debates |

**Excluded tools** (and why):
- `compute_iv_for_strike` — too narrow for generalist queries
- `fetch_correlation` — risk-specific, rarely needed in research
- `fetch_portfolio_exposure` — risk-specific
- `fetch_unusual_activity` — flow-specific deep-dive
- `fetch_sector_comparison` — overlaps with `fetch_earnings_history`
- `fetch_related_ohlcv` — overlaps with `compute_indicator_on_demand`

### Tool Budget

`AgencyConfig.research_tool_budget` already exists (default: 5). `UsageLimits(request_limit=7, tool_calls_limit=5)` — 6 tools available but only 5 calls allowed, forcing prioritization.

### Desk Agent Pattern

Follows risk_desk.py pattern (custom budget):
```python
limits = UsageLimits(
    request_limit=cfg.research_tool_budget + 2,
    tool_calls_limit=cfg.research_tool_budget,
)
```

### Prompt Design

Research desk prompt is unique — emphasizes:
1. Cross-domain synthesis (not specialization)
2. Tool prioritization given budget constraints
3. Broad initial assessment before deep-diving
4. Connecting signals across domains (e.g., earnings + IV = vol event)
5. Clear about what it does NOT do (no trade recommendations)
