# Task: DeskSelector.vue Frontend Component

## Description

Build a `DeskSelector.vue` component that provides direct desk access from the web UI. Users can select a specific desk, enter a query with a ticker, and see the desk's response. The component shows desk descriptions, capability indicators (number of tools, domain), and a simple query interface. This integrates with the existing `/api/agency/query` REST endpoint.

## Acceptance Criteria

- [ ] `web/src/components/DeskSelector.vue` component with desk cards for all 7 desks
- [ ] Each desk card shows: name, description, tool count, domain badge
- [ ] Click a desk card to open a query input with the selected desk pre-set via `desk_override`
- [ ] Query submission calls `POST /api/agency/query` with `desk_override` parameter
- [ ] Response displayed in a styled panel with: desk name, response text, tools used, confidence
- [ ] Loading state during query execution
- [ ] Error state for failed queries
- [ ] TypeScript types for desk-related API models
- [ ] Component registered in router and accessible from navigation

## Technical Details

### Component Architecture

```
DeskSelector.vue
├── DeskCard (x7) — clickable cards with desk info
│   ├── Desk name (title case)
│   ├── Domain description (1-2 sentences)
│   ├── Tool count badge (e.g., "3 tools")
│   └── Domain icon/color
├── QueryPanel (shown when desk selected)
│   ├── Ticker input (validated, uppercase)
│   ├── Query textarea
│   ├── Submit button
│   └── Back button (deselect desk)
└── ResponsePanel (shown after query completes)
    ├── Desk name header
    ├── Response text (formatted)
    ├── Tools used list
    ├── Confidence badge (reuse ConfidenceBadge.vue)
    └── New query button
```

### API Integration

```typescript
// POST /api/agency/query
interface AgencyQueryRequest {
  query_text: string;
  ticker: string;
  desk_override?: string;  // DeskType value e.g., "trend"
}

// Response: AgencyResponse model
interface AgencyResponse {
  query_id: string;
  query_text: string;
  intent: QueryIntent;
  desk_responses: DeskResponse[];
  synthesis: string;
  citations: Citation[];
  confidence: number;
  created_at: string;
}
```
