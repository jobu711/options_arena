# Task: Valuation & Position Sizing Tool Wrappers

## Description
Add two analysis tool wrappers to `agents/_toolsets.py`: `compute_composite_valuation_tool` (multi-methodology equity valuation) and `compute_position_size_tool` (volatility-regime-aware position sizing). Also update `analysis/__init__.py` to re-export all 4 analysis functions.

## Acceptance Criteria
- [ ] `compute_composite_valuation_tool` accepts ticker, fetches fundamentals, builds FDData, returns formatted CompositeValuation string
- [ ] `compute_position_size_tool` accepts ticker + annualized_iv (+ optional correlation), returns formatted PositionSizeResult string
- [ ] Both tools follow never-raises contract — return `"Error: ..."` on any exception
- [ ] Both tools validate ticker with `_validate_ticker()` and append to `ctx.deps.tools_used`
- [ ] `analysis/__init__.py` re-exports `compute_composite_valuation`, `compute_correlation_matrix`, `compute_risk_adjusted_metrics`, `compute_position_size`
- [ ] Unit tests cover success, error, and edge cases for both tools

## Technical Details
- Tool wrappers are thin adapters: call underlying pure function, format output as string
- `compute_composite_valuation_tool` must construct `FDData` from `MarketContext.fd_*` fields or fetch via ticker_info. Since desk agents have service access via `ctx.deps`, the tool can fetch `ticker_info` for current_price and construct a minimal `FDData`. For a full valuation, the tool should accept the ticker and try to build FDData from available context (the LLM may provide some fundamental values via its context)
- `compute_position_size_tool` is simpler — takes IV directly as parameter, calls pure function
- Follow existing tool pattern in `_toolsets.py` (see `fetch_quote`, `compute_iv_for_strike`)

### Edge Cases
- Ticker with all-None fundamental data: valuation should still return (models handle missing data)
- Non-finite IV (NaN/Inf): position sizing defaults to Tier 4
- Zero or negative current_price: valuation returns empty result
