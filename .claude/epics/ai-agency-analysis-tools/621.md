# Task: Correlation Matrix & Risk-Adjusted Metrics Tool Wrappers

## Description
Add two analysis tool wrappers to `agents/_toolsets.py`: `compute_correlation_matrix_tool` (portfolio correlation from OHLCV data) and `compute_risk_adjusted_metrics_tool` (Sharpe, Sortino, max drawdown from outcome data). These are medium-complexity wrappers requiring multi-ticker OHLCV fetching and repository queries respectively.

## Acceptance Criteria
- [ ] `compute_correlation_matrix_tool` accepts ticker + comparison tickers, fetches OHLCV, builds DataFrame dict, returns formatted correlation matrix
- [ ] `compute_risk_adjusted_metrics_tool` accepts ticker, queries repo for outcome data, computes Sharpe/Sortino/drawdown
- [ ] Both tools follow never-raises contract — return `"Error: ..."` on any exception
- [ ] Both tools validate tickers with `_validate_ticker()` / `TICKER_RE` and append to `ctx.deps.tools_used`
- [ ] Comparison tickers capped at 5 (reuse existing `_MAX_CORRELATION_TICKERS`)
- [ ] Unit tests cover success, error, insufficient data, and edge cases

## Technical Details
- `compute_correlation_matrix_tool` must build `dict[str, pd.DataFrame]` from OHLCV lists. Fetch OHLCV for each ticker in parallel via `asyncio.gather(..., return_exceptions=True)`. Convert `list[OHLCV]` to DataFrame with "Close" column. Pass to `compute_correlation_matrix()`.
- `compute_risk_adjusted_metrics_tool` needs outcome data. Use `ctx.deps.repo.get_outcomes_for_ticker(ticker)` (if available) or `get_contracts_for_ticker` + outcome data. Returns should be P&L percentages, holding_days from outcome records.
- Format correlation matrix as readable table: ticker pairs with correlation values
- Format risk metrics as labeled lines: Sharpe, Sortino, max drawdown, annualized return
