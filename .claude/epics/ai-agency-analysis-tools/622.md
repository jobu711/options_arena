# Task: Yang-Zhang Historical Volatility Tool Wrapper

## Description
Add `compute_hv_yang_zhang_tool` to `agents/_toolsets.py`. This tool wraps the Yang-Zhang (2000) historical volatility estimator from `indicators/hv_estimators.py`. Medium complexity due to OHLC Series splitting — must construct 4 separate pandas Series (open, high, low, close) from OHLCV data.

## Acceptance Criteria
- [ ] `compute_hv_yang_zhang_tool` accepts ticker + optional period (default 20), fetches OHLCV, computes HV
- [ ] Tool constructs 4 pandas Series (open, high, low, close) from OHLCV list
- [ ] Returns formatted string with annualized volatility, period, and interpretation
- [ ] Returns `"Error: ..."` on any exception (never-raises contract)
- [ ] Validates ticker with `_validate_ticker()` and appends to `ctx.deps.tools_used`
- [ ] Handles `None` return from `compute_hv_yang_zhang` (insufficient data)
- [ ] Unit tests cover success, insufficient data, and error cases

## Technical Details
- Fetch OHLCV via `ctx.deps.market_data.fetch_ohlcv(ticker, period="1y")` — same pattern as `compute_indicator_on_demand`
- Build 4 pandas Series from OHLCV list: `pd.Series([float(bar.open) for bar in ohlcv_list], index=[bar.date for bar in ohlcv_list])` (and same for high, low, close)
- Call `compute_hv_yang_zhang(open_series, high_series, low_series, close_series, period=period)`
- If result is `None`, return informative message about insufficient data
- Format as: `"Yang-Zhang HV({period}) for {ticker}: {value:.1%} annualized"` with interpretation (e.g., "elevated" if > 40%, "low" if < 15%, "moderate" otherwise)
- Clamp period parameter to [2, 60] to prevent abuse
