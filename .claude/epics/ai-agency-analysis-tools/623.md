## Description
Register all 5 new analysis tool wrappers on their target desks by updating the toolset builder functions and desk prompts. This is the integration task that wires everything together.

- [ ] `build_volatility_toolset()` includes `compute_hv_yang_zhang_tool` (4 tools total)
- [ ] `build_fundamental_toolset()` includes `compute_composite_valuation_tool` (4 tools total)
