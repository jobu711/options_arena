# Task: DeskDeps Dataclass and Base Tool Wrappers

## Description

Create the `DeskDeps` dataclass (dependency injection for desk agents) and the
`FunctionToolset` builder infrastructure with base service tool wrappers. This provides
the tool execution layer that desk agents use to fetch data and perform analysis.

`DeskDeps` follows the existing `DebateDeps` pattern -- a `@dataclass` with service
instances injected by the caller. Tool wrapper functions accept `RunContext[DeskDeps]`
and return formatted strings (never raise). Each tool appends its name to
`ctx.deps.tools_used` for observability.

## Acceptance Criteria

- [ ] `DeskDeps` dataclass in `agents/_desk_deps.py` with all required service fields
- [ ] `tools_used: list[str]` field with `field(default_factory=list)` on DeskDeps
- [ ] `build_volatility_toolset()` returns a list of tool functions (3 tools)
- [ ] `build_risk_toolset()` returns a list of tool functions (3 tools)
- [ ] All tool wrappers return `str`, never raise exceptions
- [ ] All tool wrappers append their name to `ctx.deps.tools_used`
- [ ] All tests pass, no lint or type errors

## Technical Details

### DeskDeps Dataclass (agents/_desk_deps.py)

```python
from __future__ import annotations

from dataclasses import dataclass, field

from options_arena.data.repository import Repository
from options_arena.services.fred import FredService
from options_arena.services.market_data import MarketDataService
from options_arena.services.options_data import OptionsDataService


@dataclass
class DeskDeps:
    """Dependency injection for desk agents.

    Follows the DebateDeps pattern -- a plain dataclass (PydanticAI convention).
    Service instances are injected by the caller (CLI or API layer).
    ``tools_used`` accumulates tool names during a query for observability.
    """

    query: str
    ticker: str
    market_data: MarketDataService
    options_data: OptionsDataService
    fred: FredService
    repo: Repository
    tools_used: list[str] = field(default_factory=list)
```

### Tool Wrappers (agents/_toolsets.py)

Each tool function follows this contract:
1. Accept `RunContext[DeskDeps]` as first parameter (PydanticAI convention)
2. Return `str` -- formatted data or error message
3. Never raise -- catch all exceptions and return `"Error: {message}"`
4. Append tool name to `ctx.deps.tools_used` before returning
5. Format output as `"{label}: {value}\n"` per data point (FinRobot pattern)

```python
from __future__ import annotations

import logging
from typing import TYPE_CHECKING

from pydantic_ai import RunContext

if TYPE_CHECKING:
    from options_arena.agents._desk_deps import DeskDeps

logger = logging.getLogger(__name__)


async def fetch_quote(ctx: RunContext[DeskDeps], ticker: str) -> str:
    """Fetch current quote for a ticker. Returns formatted price data."""
    try:
        quote = await ctx.deps.market_data.fetch_quote(ticker)
        ctx.deps.tools_used.append("fetch_quote")
        lines = [
            f"Price: ${quote.price}",
            f"Change: {quote.change:+.2f} ({quote.change_percent:+.2f}%)",
            f"Volume: {quote.volume:,}",
        ]
        if quote.fifty_two_week_high is not None:
            lines.append(f"52W High: ${quote.fifty_two_week_high}")
        if quote.fifty_two_week_low is not None:
            lines.append(f"52W Low: ${quote.fifty_two_week_low}")
        return "\n".join(lines)
    except Exception as exc:
        ctx.deps.tools_used.append("fetch_quote")
        logger.warning("fetch_quote failed for %s: %s", ticker, exc)
        return f"Error: Could not fetch quote for {ticker}: {exc}"


async def fetch_vol_surface_slice(ctx: RunContext[DeskDeps], ticker: str) -> str:
    """Fetch volatility surface data for a ticker. Returns IV by strike/expiry."""
    try:
        chains = await ctx.deps.options_data.fetch_option_chain(ticker)
        ctx.deps.tools_used.append("fetch_vol_surface_slice")
        if not chains:
            return f"Error: No option chains available for {ticker}"
        lines: list[str] = [f"Vol Surface Slice for {ticker}:"]
        for contract in chains[:10]:  # limit to 10 contracts for prompt budget
            lines.append(
                f"  Strike: ${contract.strike} | "
                f"Exp: {contract.expiration} | "
                f"IV: {contract.market_iv:.1%} | "
                f"Type: {contract.option_type.value}"
            )
        return "\n".join(lines)
    except Exception as exc:
        ctx.deps.tools_used.append("fetch_vol_surface_slice")
        logger.warning("fetch_vol_surface_slice failed for %s: %s", ticker, exc)
        return f"Error: Could not fetch vol surface for {ticker}: {exc}"


async def compute_iv_for_strike(
    ctx: RunContext[DeskDeps], ticker: str, strike: float, expiry: str,
) -> str:
    """Compute implied volatility for a specific strike and expiry."""
    try:
        chains = await ctx.deps.options_data.fetch_option_chain(ticker, expiry_date=expiry)
        ctx.deps.tools_used.append("compute_iv_for_strike")
        if not chains:
            return f"Error: No contracts found for {ticker} at strike {strike} exp {expiry}"
        # Find closest strike
        closest = min(chains, key=lambda c: abs(float(c.strike) - strike))
        return (
            f"IV for {ticker} ${closest.strike} {expiry}: {closest.market_iv:.1%}\n"
            f"Bid: ${closest.bid} | Ask: ${closest.ask} | Mid: ${closest.mid}\n"
            f"Volume: {closest.volume:,} | OI: {closest.open_interest:,}"
        )
    except Exception as exc:
        ctx.deps.tools_used.append("compute_iv_for_strike")
        logger.warning("compute_iv_for_strike failed: %s", exc)
        return f"Error: Could not compute IV for {ticker} ${strike} {expiry}: {exc}"


async def fetch_correlation(
    ctx: RunContext[DeskDeps], ticker: str, tickers: str,
) -> str:
    """Fetch correlation data between ticker and a comma-separated list of tickers."""
    try:
        ticker_list = [t.strip().upper() for t in tickers.split(",") if t.strip()]
        ctx.deps.tools_used.append("fetch_correlation")
        if not ticker_list:
            return "Error: No comparison tickers provided"
        # Fetch OHLCV for all tickers and compute pairwise correlations
        lines = [f"Correlation analysis for {ticker} vs {', '.join(ticker_list)}:"]
        for comp in ticker_list:
            try:
                primary_df = await ctx.deps.market_data.fetch_ohlcv(ticker)
                comp_df = await ctx.deps.market_data.fetch_ohlcv(comp)
                if primary_df is not None and comp_df is not None:
                    corr = primary_df["close"].pct_change().corr(
                        comp_df["close"].pct_change()
                    )
                    lines.append(f"  {ticker} vs {comp}: {corr:.3f}")
                else:
                    lines.append(f"  {ticker} vs {comp}: Data unavailable")
            except Exception:
                lines.append(f"  {ticker} vs {comp}: Computation failed")
        return "\n".join(lines)
    except Exception as exc:
        ctx.deps.tools_used.append("fetch_correlation")
        logger.warning("fetch_correlation failed: %s", exc)
        return f"Error: Could not compute correlations for {ticker}: {exc}"


async def fetch_portfolio_exposure(ctx: RunContext[DeskDeps], ticker: str) -> str:
    """Fetch portfolio exposure data for a ticker from the repository."""
    try:
        ctx.deps.tools_used.append("fetch_portfolio_exposure")
        # Query recent recommended contracts for this ticker
        contracts = await ctx.deps.repo.get_recommended_contracts_for_ticker(ticker)
        if not contracts:
            return f"No historical positions found for {ticker}"
        lines = [f"Portfolio exposure for {ticker}: {len(contracts)} historical position(s)"]
        for contract in contracts[:5]:  # limit for prompt budget
            lines.append(
                f"  {contract.option_type} ${contract.strike} "
                f"exp {contract.expiration} | Entry: ${contract.entry_mid}"
            )
        return "\n".join(lines)
    except Exception as exc:
        ctx.deps.tools_used.append("fetch_portfolio_exposure")
        logger.warning("fetch_portfolio_exposure failed for %s: %s", ticker, exc)
        return f"Error: Could not fetch portfolio exposure for {ticker}: {exc}"


def build_volatility_toolset() -> list[object]:
    """Build the tool function list for the Volatility desk.

    Returns fetch_quote, fetch_vol_surface_slice, and compute_iv_for_strike.
    These are passed to Agent(..., tools=[...]) at agent construction time.
    """
    return [fetch_quote, fetch_vol_surface_slice, compute_iv_for_strike]


def build_risk_toolset() -> list[object]:
    """Build the tool function list for the Risk desk.

    Returns fetch_quote, fetch_correlation, and fetch_portfolio_exposure.
    These are passed to Agent(..., tools=[...]) at agent construction time.
    """
    return [fetch_quote, fetch_correlation, fetch_portfolio_exposure]
```

### PydanticAI Tool Integration Pattern

PydanticAI agents accept tools as a list of callables. The agent framework inspects
the function signature -- `RunContext[DeskDeps]` as the first parameter signals that it
receives the deps context. The remaining parameters become the tool's input schema.

```python
from pydantic_ai import Agent
from options_arena.agents._desk_deps import DeskDeps
from options_arena.agents._toolsets import build_volatility_toolset

vol_desk_agent: Agent[DeskDeps, DeskResponse] = Agent(
    model=None,
    deps_type=DeskDeps,
    output_type=DeskResponse,
    tools=build_volatility_toolset(),
)
```

### Edge Cases

- Service returns `None` -- tool returns error string, does not crash
- Service raises exception -- tool catches and returns `"Error: ..."` string
- Empty ticker string -- handled gracefully (service may raise, caught by tool)
- `tools_used` list not shared between DeskDeps instances (default_factory isolation)
- `fetch_correlation` with empty tickers string -- returns error message
- `fetch_portfolio_exposure` with no historical contracts -- returns informational message
- Tool appends to `tools_used` even on error path (observability)

### Mocking Strategy

- `MagicMock()` for service instances passed to DeskDeps constructor
- `AsyncMock(return_value=...)` for successful service method calls
- `AsyncMock(side_effect=RuntimeError(...))` for service failure simulation
- `MagicMock()` for `RunContext` with `ctx.deps` pointing to the DeskDeps instance
- No real service connections, no database, no network calls
- `pydantic_ai.models.ALLOW_MODEL_REQUESTS = False` not needed here (no agent.run calls)
