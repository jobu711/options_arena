# Task: Risk Desk Agent + Prompt + Tests

## Description

Create the Risk desk agent for interactive mode, distinct from the existing debate risk agent. The Risk desk has a higher tool budget (5 vs volatility desk's 3) reflecting its broader analytical scope across portfolio risk, position sizing, correlation, and hedging. This task also updates `agents/__init__.py` to re-export both desk agents and shared desk types.

The Risk desk is the "most tool-rich desk" — it starts with 3 base tools now and later gains 3 analysis + 2 ML tools (Epics 7-8) totaling 8 available tools. The budget of 5 forces the agent to prioritize which tools to call per query.

## Technical Details

### Agent Module: `agents/risk_desk.py`

- Module-level `risk_desk: Agent[DeskDeps, str]` instance
  - `Agent(model=None, deps_type=DeskDeps, output_type=str, retries=2)`
  - Dynamic system prompt via `@risk_desk.system_prompt(dynamic=True)` — uses `dynamic=True` because risk desk may receive prior context (matching debate risk agent pattern)
  - NO `@output_validator` — `output_type=str` requires no structured validation
  - Higher tool budget: `UsageLimits(tool_calls_limit=5)`

### Helper: `run_risk_desk_query()`

Located in `agents/risk_desk.py`:
- Wraps `risk_desk.run()` with `asyncio.wait_for(timeout=config.agent_timeout)`
- Passes `FunctionToolset` via `toolsets=[build_risk_toolset()]`
- Passes `UsageLimits(tool_calls_limit=5)` for budget enforcement
- Strips `<think>` tags from `result.output` before returning
- Catches ALL exceptions -> returns error `DeskResponse` (never-raises pattern)

### Prompt: `agents/prompts/desk_risk.py`

- `DESK_RISK_PROMPT` constant, ~2000 chars, conversational tone
- Mentions available tools: `fetch_quote`, `fetch_correlation`, `fetch_portfolio_exposure`
- NO `PROMPT_RULES_APPENDIX` concatenation (debate agents only)
- Focus areas: portfolio risk quantification, position sizing, correlation analysis, exposure assessment, hedging strategies
- Include `<<<AVAILABLE_TOOLS>>>` block placeholder (dynamically populated in Epic 8)

### Re-exports: `agents/__init__.py`

Update to add:
- `vol_desk` (from `volatility_desk`)
- `risk_desk` (from `risk_desk`)
- `DeskDeps` (from wherever task 001 defined it)
- Any shared desk helpers (e.g., `run_desk_query` if generalized)

### Edge Cases

- All 5 tool calls used (budget exhausted — agent must still produce response)
- Agent produces risk assessment with empty correlation data (tools return no data)
- Timeout on `agent.run()` via `asyncio.wait_for` — fallback error response
- Agent produces empty string — should pass through without crash
- Model returns with `<think>...</think>` wrapper — stripped by `run_risk_desk_query()`

### Mocking Strategy

- **TestModel** for PydanticAI agent — never real API calls
- **AsyncMock** for all services in `DeskDeps` (`MarketDataService`, `OptionsDataService`, `FredService`)
- **Mock Repository** for data access methods (e.g., `get_portfolio_exposure()`)
- Use `agent.override(model=TestModel())` context manager for test isolation
