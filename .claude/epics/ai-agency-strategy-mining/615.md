# Task: Strategy mining engine — mine_patterns, test_significance, generate_rules

## Description
Implement the core strategy mining algorithms in `learning/strategy_book.py`. This includes outcome pattern mining via dimensional grouping (sector × IV bucket × DTE bucket × direction), chi-squared significance testing, and strategy rule generation from significant patterns. All functions follow the learning module's never-raises contract and middle-stack architecture rules.

## Acceptance Criteria
- [ ] `mine_patterns()` groups outcomes by sector × IV bucket × DTE bucket × direction dimensions
- [ ] `test_significance()` applies chi-squared test with p < 0.05, minimum 20 samples per cell
- [ ] `generate_rules()` creates `StrategyRule` candidates from significant patterns
- [ ] Minimum data guard: requires 100 total outcomes before mining is available
- [ ] Pure computation functions take data in, return results out (no DB access in core functions)
- [ ] Orchestration wrapper `run_strategy_mining()` handles DB reads/writes
- [ ] Never-raises contract on orchestration function
- [ ] All functions return typed models or typed aliases, never raw dicts

## Technical Details

### File: `learning/strategy_book.py`

#### Dimensional Grouping
```python
# IV buckets (implied volatility rank ranges)
IV_BUCKETS = [(0, 25, "low"), (25, 50, "mid_low"), (50, 75, "mid_high"), (75, 100, "high")]

# DTE buckets (days to expiration)
DTE_BUCKETS = [(0, 30, "short"), (30, 60, "medium"), (60, 120, "long"), (120, 365, "extended")]
```

Group key: `(sector, iv_bucket, dte_bucket, direction)` — each unique combination is a "cell".

#### Core Functions (Pure Computation)

1. **`mine_patterns(outcomes: list[OutcomeWithContext]) -> list[PatternCell]`**
   - Input: list of outcomes enriched with sector, IV rank, DTE at entry, direction
   - Group by dimensional key
   - Compute per-cell: win_rate, avg_return, sample_size
   - Return cells with sample_size >= 20
   - `OutcomeWithContext` is a new internal model (not exported) combining ContractOutcome fields with dimensional context
   - `PatternCell` is a new internal model: key tuple, win_rate, avg_return, sample_size

2. **`test_significance(cells: list[PatternCell], baseline_win_rate: float) -> list[PatternCell]`**
   - Chi-squared test: observed vs expected win rate per cell
   - Keep cells where p < 0.05 (statistically significant deviation from baseline)
   - Uses `scipy.stats.chi2_contingency` or manual chi-squared calculation
   - Returns only significant cells

3. **`generate_rules(significant_cells: list[PatternCell]) -> list[StrategyRule]`**
   - Convert each significant PatternCell into a StrategyRule
   - Generate unique `rule_id` (e.g., `f"rule_{sector}_{iv}_{dte}_{dir}"`)
   - Build `conditions` list from cell dimensions (sector, IV range, DTE range, direction)
   - Format human-readable `pattern` string
   - Set `status = RuleStatus.CANDIDATE`

4. **`render_learned_patterns(rules: list[StrategyRule]) -> str`**
   - Filter to `status == RuleStatus.APPROVED` only
   - Format as delimited text block:
     ```
     <<<LEARNED_PATTERNS>>>
     Pattern: {pattern}
     Win Rate: {win_rate:.1%} (n={sample_size})
     Avg Return: {avg_return:+.1%}
     ---
     <<<END_LEARNED_PATTERNS>>>
     ```
   - Return empty string if no approved rules

#### Orchestration Wrapper

5. **`run_strategy_mining(repo: Repository) -> list[StrategyRule]`**
   - Fetch outcomes from DB via existing `AnalyticsMixin` methods
   - Guard: if total outcomes < 100, log warning and return empty list
   - Call `mine_patterns()` → `test_significance()` → `generate_rules()`
   - Save generated rules via `repo.save_strategy_rule()` (from Task 614)
   - Never-raises: catch all exceptions, log, return empty list

### Edge Cases
- All outcomes in same dimension cell: produces single cell
- Exactly 20 samples per cell: included (boundary case)
- 19 samples per cell: excluded
- Win rate of 0.0 or 1.0: valid (extreme but possible)
- All rules rejected (none significant): returns empty list
- scipy import failure: never-raises contract returns empty list
