# Task: CLI eval subcommand group

## Description
Add an `eval` subcommand group to the Typer CLI with four commands: `define` (create eval definition), `check` (run evals and compare to baseline), `report` (show full report), and `list` (show all evals with status). Follows the existing `outcomes_app` and `agency_app` patterns.

## Acceptance Criteria
- [ ] `options-arena eval check` runs eval suite and displays pass@k + verdict
- [ ] `options-arena eval check --desk trend` filters to trend desk evals only
- [ ] `options-arena eval report` shows full report with per-eval breakdown
- [ ] `options-arena eval list` shows all eval definitions with status
- [ ] `options-arena eval define <name>` creates eval definition interactively
- [ ] Sync Typer commands with `asyncio.run()` for async internals
- [ ] Rich tables for report output
- [ ] Service lifecycle: create/close services in try/finally

## Technical Details
- New file: `src/options_arena/cli/eval.py`
- Register: `app.add_typer(eval_app, name="eval")` in `cli/commands.py`
- Follow `cli/agency.py` pattern (Typer subcommand group)
- Use Rich tables for displaying eval results
- `RichHandler(markup=False)` for logging
