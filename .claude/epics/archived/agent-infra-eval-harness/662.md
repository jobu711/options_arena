# Task: API eval endpoints

## Description
Add FastAPI REST endpoints for the eval harness: `POST /api/eval/check` (trigger eval run), `GET /api/eval/report` (latest report), and `GET /api/eval/history` (historical pass rates). Follows the existing route registration pattern in `api/routes/`.

## Acceptance Criteria
- [ ] `POST /api/eval/check` triggers eval suite and returns `EvalReport`
- [ ] `GET /api/eval/report` returns latest stored eval report
- [ ] `GET /api/eval/history` returns historical eval runs with pass rates
- [ ] Optional `desk` query parameter on check and report endpoints
- [ ] Services injected via `Depends()` (not created per-request)
- [ ] Router registered in `create_app()`
- [ ] FastAPI auto-serializes Pydantic models (no manual model_dump)

## Technical Details
- New file: `src/options_arena/api/routes/eval.py`
- Register: `app.include_router(eval_router)` in `api/app.py`
- Follow `api/routes/learning.py` pattern (similar scope)
- Eval check could be long-running — consider background task or direct await
- Dependency injection via `api/deps.py` providers
