# Task: Regression fixture generator and test suite

## Description
Build a fixture generator that queries historical wrong recommendations (high confidence + negative P&L) from the outcomes database and serializes them as JSON test fixtures. Then build a parametrized pytest suite that verifies current recommendations don't repeat known failures. This catches the "AI carries the same assumptions" blind spot.

## Acceptance Criteria
- [ ] `tools/generate_regression_fixtures.py` script queries wrong recommendations
- [ ] Fixtures include serialized `MarketContext` + `TickerScore` snapshots
- [ ] Fixtures stored as JSON in `tests/regression/fixtures/` (git-tracked)
- [ ] Parametrized pytest suite in `tests/regression/test_recommendation_regression.py`
- [ ] Tests assert new recommendations don't repeat high-confidence failures
- [ ] Tests use `TestModel` — no real API calls
- [ ] `@pytest.mark.regression` marker for selective running

## Technical Details
- New script: `tools/generate_regression_fixtures.py`
- New directory: `tests/regression/` with `conftest.py` and test file
- New directory: `tests/regression/fixtures/` for JSON fixture files
- Fixture format: `{ticker, market_context_json, ticker_score_json, actual_pnl_pct, original_direction, original_confidence}`
- Query: outcomes where `confidence >= 0.6 AND contract_return_pct < -20.0`
- Test assertion: if original was wrong with high confidence, new recommendation should be more cautious (lower confidence or different direction)

## Test Plan

### Test Files
- `tests/regression/test_recommendation_regression.py`

### Test Cases
```python
@pytest.mark.regression
class TestRecommendationRegression:
    @pytest.mark.parametrize("fixture", load_regression_fixtures())
    async def test_no_high_confidence_repeat(self, fixture) -> None:
        """Verify current model doesn't repeat known high-confidence failure."""

    def test_fixture_loader_handles_empty_dir(self) -> None:
        """Verify empty fixtures directory produces no test cases (not error)."""

    def test_fixture_format_valid(self) -> None:
        """Verify each fixture deserializes to valid MarketContext + TickerScore."""

    async def test_synthesis_reduces_confidence_on_failure(self) -> None:
        """Verify synthesis shows reduced confidence for known failure ticker."""

    def test_sample_fixture_exists(self) -> None:
        """Verify at least one fixture committed for bootstrap."""
```

### Edge Cases
- No fixture files — test suite collects 0 tests (not error)
- Fixture with missing fields — skip with warning
- Very old fixture (stale MarketContext) — still valid for regression check
- Generator finds no wrong recommendations — produces empty fixtures dir

### Mocking Strategy
- `TestModel` for desk/synthesis agent runs
- `ALLOW_MODEL_REQUESTS = False` at module level
- Mock Repository for generator script tests
- Synthetic fixture for bootstrap (committed to repo)
