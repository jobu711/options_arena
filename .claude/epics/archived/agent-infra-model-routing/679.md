# Task: Models, Enums, and Config for Model Routing

## Description
Add the foundational data models, enum, and configuration for complexity-based model routing. This includes `ModelTier` StrEnum, `DeskMetrics`, `AssessmentSummary`, and `RecommendationCost` frozen models, `RoutingConfig` nested on `DebateConfig`, and extending `RecommendationResult` with `desk_metrics`, `assessment_summary`, and `cost` fields.

## Acceptance Criteria
- [ ] `ModelTier` StrEnum has 3 members: FAST, STANDARD, PREMIUM
- [ ] `DeskMetrics` frozen model captures per-desk timing, status, model used, token usage
- [ ] `AssessmentSummary` frozen model captures direction votes, avg confidence, disagreement desks, risk flags, data completeness
- [ ] `RecommendationCost` frozen model aggregates total tokens, cost USD, per-desk breakdown
- [ ] `RoutingConfig` BaseModel nested on `DebateConfig` with thresholds and pricing map
- [ ] `RecommendationResult` extended with `desk_metrics: list[DeskMetrics]`, `assessment_summary: AssessmentSummary | None`, and `cost: RecommendationCost | None`
- [ ] All models re-exported from `models/__init__.py`
- [ ] JSON round-trip works for all new models
- [ ] All validators use `math.isfinite()` before range checks

## Technical Details
- `ModelTier` goes in `enums.py` (alongside existing StrEnums)
- `DeskMetrics` and `RecommendationCost` go in `recommendation.py` (alongside existing recommendation models)
- `RoutingConfig` goes in `config.py` as a `BaseModel` (NOT `BaseSettings`)
- `RoutingConfig` nested on `DebateConfig` as `routing: RoutingConfig = RoutingConfig()`
- `cost_per_million_tokens` on `RoutingConfig` maps model name strings to float prices
- `DeskMetrics.status` uses a simple string: "success" or "fallback"
- `DeskMetrics.token_usage` stores input + output token counts
- `RecommendationCost.per_desk` is `list[DeskMetrics]` (re-use, not a separate type)

### Action
1. In `src/options_arena/models/enums.py`, add `ModelTier(StrEnum)` with FAST, STANDARD, PREMIUM
   - WHY: all categorical fields must be StrEnum per project rules
2. In `src/options_arena/models/recommendation.py`, add `DeskMetrics` frozen model:
   - `desk: DeskType` — which desk produced this
   - `status: str` — "success" or "fallback"
   - `duration_ms: int` — wall-clock time for this desk
   - `model_tier: ModelTier` — which tier was selected
   - `model_used: str` — actual model name string
   - `input_tokens: int = 0` — input token count
   - `output_tokens: int = 0` — output token count
   - WHY: captures per-desk observability data required for cost tracking
3. In `src/options_arena/models/recommendation.py`, add `AssessmentSummary` frozen model:
   - `direction_votes: dict[SignalDirection, int]` — vote count per direction from 6 desks
   - `avg_confidence: float` — mean confidence across desks (isfinite + [0,1] validator)
   - `disagreement_desks: list[DeskType]` — desks that disagree with majority direction
   - `risk_flags: list[str]` — extracted from RiskDeskAssessment
   - `data_completeness: float` — fraction of non-None domain fields (isfinite + [0,1] validator)
   - WHY: computed between Phase 1 (desks) and Phase 2 (synthesis), injected into synthesis prompt to support agent_agreement_score and dissenting_desks on PositionRecommendation
4. In `src/options_arena/models/recommendation.py`, add `RecommendationCost` frozen model:
   - `total_input_tokens: int`
   - `total_output_tokens: int`
   - `total_cost_usd: float`
   - `tier_distribution: dict[ModelTier, int]` — count of desks per tier
   - Validators: `isfinite()` on `total_cost_usd`, non-negative on token counts
   - WHY: aggregates cost data across all desks for display and analytics
5. In `src/options_arena/models/config.py`, add `RoutingConfig(BaseModel)`:
   - `enable_model_routing: bool = False` — opt-in, backward compatible
   - `complexity_threshold_fast: float = 0.3` — below this → FAST
   - `complexity_threshold_premium: float = 0.7` — above this → PREMIUM
   - `fast_model: str = "llama-3.1-8b-instant"` — model for FAST tier
   - `premium_model: str = ""` — empty means use default model (no separate premium)
   - `cost_per_million_tokens: dict[str, float]` — pricing map with sensible defaults
   - Validators: `isfinite()` + range on thresholds, fast < premium
   - WHY: config-driven routing with backward compat (disabled by default)
6. In `src/options_arena/models/config.py`, nest `RoutingConfig` on `DebateConfig`:
   - Add `routing: RoutingConfig = RoutingConfig()`
   - WHY: follows existing nesting pattern (ScanConfig has MLConfig, etc.)
7. In `src/options_arena/models/recommendation.py`, extend `RecommendationResult`:
   - Add `desk_metrics: list[DeskMetrics] = Field(default_factory=list)`
   - Add `assessment_summary: AssessmentSummary | None = None`
   - Add `cost: RecommendationCost | None = None`
   - WHY: optional fields with defaults preserve backward compat
8. In `src/options_arena/models/__init__.py`, re-export `ModelTier`, `DeskMetrics`, `AssessmentSummary`, `RecommendationCost`, `RoutingConfig`
   - WHY: standard re-export pattern for public API
