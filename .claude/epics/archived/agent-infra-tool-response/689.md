### Special Considerations

- **ML tools**: Already have `try: from ... import` pattern for guarded imports. On
  `ImportError`, return ToolResponse with ERROR status and `next_actions` suggesting
  alternative analysis methods.
- **Synthesis tools**: Use `RunContext[object]` with attribute access (`ctx.deps.context`,
  `ctx.deps.contracts`). Do NOT call `ctx.deps.tools_used.append()` — SynthesisDeps
  has a separate `tools_used` field that's populated by the synthesis agent wrapper.
  Preserve this asymmetry.
