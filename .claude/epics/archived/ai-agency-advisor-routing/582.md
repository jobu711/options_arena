## Technical Details

### Migration File (data/migrations/034_agency_queries.sql)

```sql
-- Migration 034: Agency query persistence
-- Stores agency routing queries, intents, and synthesized responses for audit trail.

CREATE TABLE IF NOT EXISTS agency_queries (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    query_id TEXT NOT NULL UNIQUE,
    query_text TEXT NOT NULL,
    desk TEXT,
    tickers_json TEXT,
    intent_json TEXT,
    response_json TEXT,
    confidence REAL,
    created_at TEXT NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_agency_queries_query_id
    ON agency_queries(query_id);

CREATE INDEX IF NOT EXISTS idx_agency_queries_created_at
    ON agency_queries(created_at);
```

Column mapping:
- `query_id` -- UUID4 string, unique identifier for the query (from `AgencyQuery.query_id`)
- `query_text` -- the raw user query string
- `desk` -- comma-separated desk names dispatched to (from `QueryIntent.desks`)
- `tickers_json` -- JSON array of extracted tickers (from `QueryIntent.tickers`)
- `intent_json` -- full `QueryIntent.model_dump_json()` for reconstruction
- `response_json` -- full `AgencyResponse.model_dump_json()` for reconstruction
- `confidence` -- float confidence from the synthesized response
- `created_at` -- ISO 8601 UTC timestamp

### AgencyMixin (data/_agency.py)

```python
"""Agency query persistence mixin for Repository."""

from __future__ import annotations

import json
import logging
from typing import TYPE_CHECKING

from ._base import RepositoryBase

if TYPE_CHECKING:
    from options_arena.models import AgencyQuery, AgencyResponse, QueryIntent

logger = logging.getLogger(__name__)


class AgencyMixin(RepositoryBase):
    """CRUD operations for agency queries.

    Methods
    -------
    save_agency_query
        Persist a completed agency query with its intent and response.
    get_agency_query
        Retrieve a single agency response by query_id.
    list_agency_queries
        List recent agency queries, newest first.
    """

    async def save_agency_query(
        self,
        query: AgencyQuery,
        intent: QueryIntent,
        response: AgencyResponse,
        *,
        commit: bool = True,
    ) -> int:
        """Persist an agency query and its response.

        Parameters
        ----------
        query
            The original user query.
        intent
            The classified intent (desks, query type, tickers).
        response
            The synthesized agency response.
        commit
            Whether to commit immediately (default True).
            Set False for batched persistence.

        Returns
        -------
        int
            The database row ID of the inserted record.
        """
        desk_str = ",".join(d.value for d in intent.desks)
        tickers_json = json.dumps(intent.tickers)
        intent_json = intent.model_dump_json()
        response_json = response.model_dump_json()

        cursor = await self._db.execute(
            """
            INSERT INTO agency_queries
                (query_id, query_text, desk, tickers_json, intent_json,
                 response_json, confidence, created_at)
            VALUES (?, ?, ?, ?, ?, ?, ?, ?)
            """,
            (
                query.query_id,
                query.query_text,
                desk_str,
                tickers_json,
                intent_json,
                response_json,
                response.confidence,
                query.created_at.isoformat(),
            ),
        )
        if commit:
            await self._db.commit()
        row_id = cursor.lastrowid
        logger.debug("Saved agency query id=%d query_id=%s", row_id, query.query_id)
        return row_id  # type: ignore[return-value]

    async def get_agency_query(self, query_id: str) -> AgencyResponse | None:
        """Retrieve an agency response by query_id.

        Parameters
        ----------
        query_id
            The UUID4 string identifying the query.

        Returns
        -------
        AgencyResponse | None
            The reconstructed response, or None if not found.
        """
        from options_arena.models import AgencyResponse

        async with self._db.execute(
            "SELECT response_json FROM agency_queries WHERE query_id = ?",
            (query_id,),
        ) as cursor:
            row = await cursor.fetchone()

        if row is None:
            return None

        return AgencyResponse.model_validate_json(row["response_json"])

    async def list_agency_queries(self, limit: int = 20) -> list[AgencyResponse]:
        """List recent agency queries, newest first.

        Parameters
        ----------
        limit
            Maximum number of results to return (default 20).

        Returns
        -------
        list[AgencyResponse]
            Reconstructed responses ordered by created_at DESC.
        """
        from options_arena.models import AgencyResponse

        async with self._db.execute(
            "SELECT response_json FROM agency_queries ORDER BY created_at DESC LIMIT ?",
            (limit,),
        ) as cursor:
            rows = await cursor.fetchall()

        return [AgencyResponse.model_validate_json(row["response_json"]) for row in rows]
```

### Edge Cases

- Empty database: `get_agency_query()` returns `None`, `list_agency_queries()` returns `[]`
- Duplicate `query_id`: `save_agency_query()` raises `sqlite3.IntegrityError` (UNIQUE constraint)
- `commit=False`: data visible only after explicit `repo.commit()`
- Very long query text: no length limit in schema, should persist correctly
- Response with empty `desk_responses` list: serializes/deserializes correctly
- Response with multiple citations: serializes/deserializes correctly
- `list_agency_queries(limit=0)`: SQLite `LIMIT 0` returns empty list
- `list_agency_queries(limit=1)`: returns exactly 1 result
- Ordering: `created_at DESC` ensures newest first even when inserted out of order
- Multiple desks in intent: comma-separated `desk` column for readability, full JSON in `intent_json` for reconstruction
