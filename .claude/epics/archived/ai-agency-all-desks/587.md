## Technical Details

### Tool Implementations

**`fetch_related_ohlcv(ctx, ticker, period="6mo")`** — Trend desk
- Calls `ctx.deps.market_data.fetch_ohlcv(ticker, period)` via existing service
- Returns formatted string: last 5 bars with date, open, high, low, close, volume
- Validates ticker, catches all exceptions, returns error string on failure

**`compute_indicator_on_demand(ctx, ticker, indicator)`** — Trend desk
- Fetches OHLCV via `ctx.deps.market_data.fetch_ohlcv(ticker, "1y")`
- Computes the requested indicator using `indicators/` functions (RSI, MACD, SMA alignment)
- Supported indicators: `"rsi"`, `"macd"`, `"sma_alignment"`, `"adx"`
- Returns formatted string with current value and brief interpretation
- Import indicators lazily inside the function to avoid module-level boundary violation

**`fetch_chain_summary(ctx, ticker)`** — Flow desk
- Calls `ctx.deps.options_data.fetch_expirations(ticker)` then `fetch_chain()` for nearest expiration
- Returns summary: total calls/puts, total OI, total volume, put/call OI ratio, put/call volume ratio
- Guards division-by-zero with `denominator or 1` pattern

**`fetch_unusual_activity(ctx, ticker)`** — Flow desk
- Fetches chain for nearest expiration via `ctx.deps.options_data`
- Identifies contracts with volume > 3x open interest (unusual activity signal)
- Returns up to 5 unusual contracts sorted by volume/OI ratio
- Returns "No unusual activity detected" if none found
