# Task: Volatility Desk Agent + Prompt + Tests

## Description

Create the Volatility desk agent for interactive mode, distinct from the existing debate volatility agent. This agent uses conversational prompts, returns plain `str` output (no structured Pydantic model), integrates with the tool system via `FunctionToolset`, and enforces a tool-call budget via `UsageLimits`. Full test coverage included.

The desk agent follows the same module-level `Agent` pattern as debate agents but differs in three ways: `output_type=str`, no `@output_validator`, and tool-use via `FunctionToolset` passed at run time.

## Acceptance Criteria

- [ ] `agents/volatility_desk.py` exists with module-level `vol_desk` Agent instance
- [ ] `agents/prompts/desk_volatility.py` exists with `DESK_VOLATILITY_PROMPT` constant
- [ ] `run_desk_query()` helper wraps agent run with timeout, think-tag stripping, and never-raises
- [ ] `UsageLimits(tool_calls_limit=3)` enforced on every call
- [ ] All 10+ tests pass
- [ ] ruff + mypy --strict clean

## Technical Details

### Agent Module: `agents/volatility_desk.py`

- Module-level `vol_desk: Agent[DeskDeps, str]` instance
  - `Agent(model=None, deps_type=DeskDeps, output_type=str, retries=2)`
  - Dynamic system prompt via `@vol_desk.system_prompt(dynamic=True)` that loads from `DESK_VOLATILITY_PROMPT`
  - NO `@output_validator` — `output_type=str` requires no structured validation
  - Post-run `<think>` tag stripping via `strip_think_tags()` from `_parsing.py` (called in `run_desk_query()`, not as a validator)

### Helper: `run_desk_query()`

Located in `agents/volatility_desk.py`:
- Wraps `vol_desk.run()` with `asyncio.wait_for(timeout=config.agent_timeout)`
- Passes `FunctionToolset` via `toolsets=[build_volatility_toolset()]`
- Passes `UsageLimits(tool_calls_limit=3)` for budget enforcement
- Strips `<think>` tags from `result.output` before returning
- Catches ALL exceptions -> returns error `DeskResponse` (never-raises pattern)

### Prompt: `agents/prompts/desk_volatility.py`

- `DESK_VOLATILITY_PROMPT` constant, ~2000 chars, conversational tone
- Mentions available tools: `fetch_quote`, `fetch_vol_surface_slice`, `compute_iv_for_strike`
- NO `PROMPT_RULES_APPENDIX` concatenation (that pattern is for debate agents only)
- Focus areas: IV surface analysis, vol regime assessment, term structure, skew interpretation
- Include `<<<AVAILABLE_TOOLS>>>` block placeholder (dynamically populated in Epic 8)

### Edge Cases

- Agent produces empty string — should still work, no crash
- Agent produces very long output (>10K chars) — no truncation needed, pass through
- All tools fail — agent should still produce a text response
- Model returns with `<think>...</think>` wrapper — stripped by `run_desk_query()`
- Model returns with nested or multiple `<think>` blocks — all stripped

### Mocking Strategy

- **TestModel** for PydanticAI agent — never real API calls
- **AsyncMock** for `MarketDataService`, `OptionsDataService`, `FredService` in DeskDeps
- **Mock Repository** for data access methods
- Use `agent.override(model=TestModel())` context manager for test isolation
