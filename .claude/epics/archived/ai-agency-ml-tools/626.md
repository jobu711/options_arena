# Task: GARCH Forecast + Markov Regime Tool Wrappers

## Description
Create two tool wrapper functions in `agents/_toolsets.py` for ML-dependent indicators: `compute_garch_forecast_tool` (wraps `indicators/vol_forecast.py`) and `compute_markov_regime_tool` (wraps `indicators/regime_ml.py`). Both require optional `[ml]` dependencies (`arch`, `statsmodels`) and must gracefully handle ImportError when not installed.

## Acceptance Criteria
- [ ] `compute_garch_forecast_tool` fetches OHLCV, computes % log returns, calls `compute_garch_forecast`, formats annualized vol as string
- [ ] `compute_markov_regime_tool` fetches OHLCV, computes log returns, calls `compute_markov_regime`, formats regime label + probabilities as string
- [ ] Both tools follow never-raise contract — catch all exceptions, return error string
- [ ] Both tools validate ticker via `_validate_ticker()` and append to `ctx.deps.tools_used`
- [ ] Both tools use lazy imports from `indicators/` (inside try block)
- [ ] Both tools return "N/A" message when indicator returns None (insufficient data, non-stationarity, etc.)
- [ ] Both tools return graceful message when optional deps not installed (ImportError)
- [ ] Type annotations pass `mypy --strict`

## Technical Details
- GARCH tool: compute % returns as `np.log(close_arr[1:] / close_arr[:-1]) * 100` — this is what `compute_garch_forecast` expects
- Markov tool: compute plain log returns as `np.log(close_arr[1:] / close_arr[:-1])` — this is what `compute_markov_regime` expects
- Both fetch 1y OHLCV via `ctx.deps.market_data.fetch_ohlcv(ticker, period="1y")`
- Build close price Series from OHLCV list (same pattern as `compute_hv_yang_zhang_tool`)
- GARCH output: format as "GARCH(1,1) forecast for {ticker}: {vol:.1%} annualized — {interpretation}"
- Markov output: format as "Markov regime for {ticker}: {label} (prob: {prob:.1%})\nTransition probs: ..."
- `tool_name = "compute_garch_forecast"` / `"compute_markov_regime"` for observability
- Import `numpy as np` at top of file (already imported? check); lazy import indicator functions
