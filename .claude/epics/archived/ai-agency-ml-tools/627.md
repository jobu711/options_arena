# Task: Macro Regime + Hurst Exponent Tool Wrappers

## Description
Create two tool wrapper functions in `agents/_toolsets.py` for always-available indicators: `compute_macro_regime_tool` (wraps `indicators/macro.py`) and `compute_hurst_exponent_tool` (wraps `indicators/hurst.py`). Neither requires optional dependencies — they are grouped in this epic for thematic coherence.

## Acceptance Criteria
- [ ] `compute_macro_regime_tool` fetches macro context from FRED, calls `compute_macro_regime`, formats regime + confidence as string
- [ ] `compute_macro_regime_tool` handles `ctx.deps.fred is None` gracefully (return "FRED service unavailable")
- [ ] `compute_hurst_exponent_tool` fetches OHLCV, builds close Series, calls `hurst_exponent`, formats H value + interpretation
- [ ] Both tools follow never-raise contract
- [ ] Both tools validate ticker via `_validate_ticker()` (Hurst) or skip (Macro — ticker-independent)
- [ ] Both tools append to `ctx.deps.tools_used`
- [ ] Type annotations pass `mypy --strict`

## Technical Details
- Macro tool: `compute_macro_regime` takes keyword-only args from `MacroContext` fields
  - `MacroContext` has: `yield_spread_10y2y`, `unemployment_rate`, `fed_funds_rate`, `vix`, `cpi_yoy`, `completeness_ratio()`
  - Call `ctx.deps.fred.fetch_macro_context()` to get the `MacroContext`
  - Pass individual fields as kwargs to `compute_macro_regime()`
  - Output: "Macro regime: {regime.value} (confidence: {confidence:.0%})\n  Yield spread: {val}, Unemployment: {val}"
  - Note: macro regime is ticker-independent — no ticker param needed (but function still takes `ctx: RunContext[DeskDeps]`)
- Hurst tool: `hurst_exponent(close: pd.Series, min_bars=200) -> float | None`
  - Fetch OHLCV, build pd.Series of close prices
  - Output: "Hurst exponent for {ticker}: {H:.3f} — {interpretation}"
  - Interpretation: H > 0.55 "trending", H < 0.45 "mean-reverting", else "random walk"
  - `tool_name = "compute_hurst_exponent"` / `"compute_macro_regime"`

### Edge Cases
- `fred` is None on DeskDeps: macro tool returns "FRED service not available"
- FRED fetch raises: macro tool catches and returns error
- Empty OHLCV for Hurst: returns "No OHLCV data found"
- All-constant close prices: `hurst_exponent` returns None → tool returns N/A

- Mock `ctx.deps.fred.fetch_macro_context` with `AsyncMock` returning mock `MacroContext`
- Mock `ctx.deps.market_data.fetch_ohlcv` with `AsyncMock` for Hurst
- Mock `compute_macro_regime` / `hurst_exponent` via `monkeypatch`
