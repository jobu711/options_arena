# Task: Learned pattern injection into desk agent prompts

## Description
Wire approved strategy rules from the playbook into desk agent prompts at runtime. When a desk query runs, fetch approved `StrategyRule` records from the repository, render them via `render_learned_patterns()`, and inject the resulting text block into the desk agent's dynamic system prompt using the `<<<LEARNED_PATTERNS>>>` delimiter pattern. Only approved rules affect prompts — candidates and rejected rules are excluded.

## Acceptance Criteria
- [ ] Desk agent prompts include `<<<LEARNED_PATTERNS>>>` block when approved rules exist
- [ ] Only `RuleStatus.APPROVED` rules appear in injected text
- [ ] When no approved rules exist, no `<<<LEARNED_PATTERNS>>>` block is injected (clean prompt)
- [ ] `DeskDeps` dataclass extended with `learned_patterns: str = ""` field
- [ ] Pattern injection happens at agent run time, not at prompt definition time
- [ ] All 7 desk agents receive learned patterns (volatility, risk, trend, flow, fundamental, contrarian, research)
- [ ] Debate agents are NOT affected (they use `PROMPT_RULES_APPENDIX`, not learned patterns)

## Technical Details

### Approach: Dynamic Prompt Injection via DeskDeps

The desk agents already use `@agent.system_prompt` decorators. The injection follows the same pattern as `<<<PRIOR_OUTPUTS>>>` in debate agents:

1. **Extend `DeskDeps`** (in the desk agent deps definition):
   ```python
   @dataclass
   class DeskDeps:
       # ... existing fields ...
       learned_patterns: str = ""  # Pre-rendered approved patterns, empty if none
   ```

2. **Dynamic system prompt** on each desk agent:
   ```python
   @volatility_desk_agent.system_prompt(dynamic=True)
   async def vol_desk_with_patterns(ctx: RunContext[DeskDeps]) -> str:
       base = DESK_VOLATILITY_PROMPT
       if ctx.deps.learned_patterns:
           base += f"\n\n{ctx.deps.learned_patterns}"
       return base
   ```

3. **Pattern fetch in routing** (in `_routing.py` or desk query wrappers):
   ```python
   # Before running desk agent
   approved_rules = await repo.get_strategy_rules(status=RuleStatus.APPROVED)
   patterns_text = render_learned_patterns(approved_rules)
   deps = DeskDeps(..., learned_patterns=patterns_text)
   ```

### Files to Modify

- `src/options_arena/agents/_toolsets.py` or relevant desk agent files — add `learned_patterns` to `DeskDeps`
- Each of the 7 desk agent files (`*_desk.py`) — convert to `dynamic=True` system prompt with pattern injection
- `src/options_arena/agents/_routing.py` — fetch approved rules and populate `learned_patterns` on DeskDeps before dispatching

### Key Constraints

- Desk prompts do NOT use `PROMPT_RULES_APPENDIX` — only debate agents do
- Static desk prompts become dynamic(True) to support runtime pattern injection
- Prompt files in `agents/prompts/desk_*.py` remain unchanged — they stay as static string constants
- Dynamic injection logic stays in agent module files, not in prompt files (per `agents/prompts/CLAUDE.md` rule)
- Token budget: learned patterns block must be < 2000 chars to stay within desk agent limits
