## Description

Wave 1 (lowest risk). Delete 4 dead functions from `indicators/`, remove their exports from `__init__.py`, and clean all downstream references in models, scoring, and scan pipeline. Delete/update associated tests.

- `classify_market_regime()` from `indicators/regime.py`
- `compute_hv_parkinson()` from `indicators/hv_estimators.py`
- `compute_hv_rogers_satchell()` from `indicators/hv_estimators.py`
- `compute_egarch_forecast()` + `_EGARCH_SIMULATIONS` from `indicators/vol_forecast.py`

Downstream references to clean:
- `vol_forecast_egarch` field from `IndicatorSignals` in `models/scan.py`

## Technical Details

- `indicators/` is a pure math module (pandas in/out). No API calls, no Pydantic models.
- Yang-Zhang mathematically subsumes Parkinson and Rogers-Satchell — no functional loss.
- GARCH is the sole parametric vol forecaster after EGARCH removal.
- ML classifiers in `regime_ml.py` are authoritative for regime detection — `classify_market_regime()` was the old pre-ML approach.
- `IndicatorSignals` is a Pydantic model — removing a field is a schema change but safe since EGARCH was always `None` when ML extras aren't installed.
