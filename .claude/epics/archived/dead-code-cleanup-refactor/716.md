# Task: Extract FiniteFieldsMixin + apply to 10 config classes

## Description
Create a `FiniteFieldsMixin` with the shared `validate_all_finite` model validator and
apply it to 10 config classes in `models/config.py` that currently duplicate the same
~6-line validator. Net reduction ~54 lines (10 x 6 lines replaced by 1 mixin + 10 inheritance changes).

## Acceptance Criteria
- [ ] `FiniteFieldsMixin` created with `validate_all_finite` model validator

- [ ] New mixin-specific tests added

## Technical Details

### Duplicated validator (identical in all 10 classes):
```python
@model_validator(mode="after")
def validate_all_finite(self) -> Self:
    """Reject NaN/Inf on all float config fields (defense-in-depth)."""
    for name, value in self.__dict__.items():
        if isinstance(value, float) and not math.isfinite(value):
            raise ValueError(f"{name} must be finite, got {value}")
    return self
```

### Config classes with this validator (10 instances):
1. `ScanConfig` (line ~176)
2. `PricingConfig` (line ~199)
3. `ServiceConfig` (line ~223)
4. `RoutingConfig` (line ~304)
5. `DebateConfig` (line ~457)
6. `IntelligenceConfig` (line ~486)
7. `FinancialDatasetsConfig` (line ~599)
8. `PositionSizingConfig` (line ~632)
9. `SpreadConfig` (line ~694)
10. `AgencyConfig` (line ~763)

### Mixin design:
```python
class FiniteFieldsMixin(BaseModel):
    """Mixin that rejects NaN/Inf on all float fields (defense-in-depth)."""

    @model_validator(mode="after")
    def validate_all_finite(self) -> Self:
        for name, value in self.__dict__.items():
            if isinstance(value, float) and not math.isfinite(value):
                raise ValueError(f"{name} must be finite, got {value}")
        return self
```

### Placement:
Define `FiniteFieldsMixin` in `models/config.py` near the top (before the first config class
that uses it). It's an internal helper, not a public model — no re-export needed.

### Inheritance change pattern:
```python
# BEFORE
class ScanConfig(BaseModel):
    ...
    @model_validator(mode="after")
    def validate_all_finite(self) -> Self: ...

# AFTER
class ScanConfig(FiniteFieldsMixin):
    ...
    # validate_all_finite inherited from mixin
```

**Note**: `FiniteFieldsMixin` inherits from `BaseModel`, so the config class replaces
`BaseModel` with `FiniteFieldsMixin` (which IS a BaseModel).
