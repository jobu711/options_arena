# Task: Slim `process_ticker_options` to ~50-line coordinator

## Description

After Tasks 1–3 extract the four helpers, `process_ticker_options` should be a
thin coordinator that:
1. Calls `_fetch_ticker_data()` → handles early return
2. Calls `_compute_dse_indicators()` → handles IV filter
3. Calls `_select_and_score_contracts()` → gets recommended contracts
4. Calls `_build_spread()` → gets spread analysis
5. Returns the result tuple

This task does the final cleanup: ensure the coordinator is clean, concise,
well-documented, and ~50 lines. Remove any leftover inline logic that should
have been extracted. Update the module docstring if needed.

### Expected final structure

```python
async def process_ticker_options(
    ticker_score: TickerScore,
    risk_free_rate: float,
    ohlcv_map: dict[str, list[OHLCV]],
    spx_close: pd.Series | None,
    *,
    # ... same parameters ...
) -> tuple[str, list[OptionContract], date | None, Decimal | None, SpreadAnalysis | None]:
    """Coordinate per-ticker Phase 3 processing.

    Delegates to focused helpers:
    1. ``_fetch_ticker_data()`` — earnings check, chain/info fetch, metadata
    2. ``_compute_dse_indicators()`` — vol surface, DSE indicators, IV filter
    3. ``_select_and_score_contracts()`` — contract recommendation + surface scoring
    4. ``_build_spread()`` — multi-leg spread construction

    Isolated per-ticker: exceptions propagate to ``asyncio.gather``.
    """
    ticker = ticker_score.ticker
    _recommend = recommend_contracts_fn or recommend_contracts
    _map_yfinance = map_yfinance_fn or map_yfinance_to_metadata

    # Step 1: Fetch data
    data = await _fetch_ticker_data(...)
    if data.filtered_out:
        return (ticker, [], data.earnings_date, data.entry_stock_price, None)
    if not data.all_contracts:
        return (ticker, [], data.earnings_date, data.entry_stock_price, None)

    spot = float(data.ticker_info.current_price)

    # Step 2: DSE indicators
    dse = _compute_dse_indicators(...)
    if dse.iv_filtered_out:
        return (ticker, [], data.earnings_date, data.entry_stock_price, None)

    # Step 3: Contract selection
    recommended = _select_and_score_contracts(...)

    # Step 4: Spread construction
    spread = _build_spread(...)

    return (ticker, recommended, data.earnings_date, data.entry_stock_price, spread)
```
