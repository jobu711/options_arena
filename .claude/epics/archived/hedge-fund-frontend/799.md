# Task: Atomic components — DeskCard, PipelineStatus, ScanProgressCard

## Description

Build three foundational atomic components used throughout the trading desk: DeskCard (universal collapsible card wrapper), PipelineStatus (stage badge for pipeline states), and ScanProgressCard (scan phase progress indicator).

## Acceptance Criteria

- [ ] `DeskCard.vue` renders header bar with title, optional status badge slot, collapse toggle; body collapses/expands; consistent dark surface styling
- [ ] `PipelineStatus.vue` renders correct icon, label, and color for all 5 stages (queued, scored, analyzing, ready, failed)
- [ ] `ScanProgressCard.vue` shows phase name, progress bar, ticker count, elapsed time; only visible during active scan
- [ ] All use `<script setup lang="ts">` with typed props
- [ ] All have scoped CSS with dark theme variables
- [ ] `npm run build` succeeds

## Technical Details

### DeskCard.vue
```typescript
interface Props {
  title: string
  collapsed?: boolean        // default false
  fullWidth?: boolean        // grid-column: 1 / -1
}
// Slots: default (body), status (header badge area)
// Emits: update:collapsed
```
- Header: title text, collapse chevron icon (rotates on toggle), optional `#status` slot
- Body: `v-show="!collapsed"` (not `v-if` — preserve DOM state)
- Styling: `background: var(--p-surface-800)`, `border: 1px solid var(--p-surface-700)`, `border-radius: 0.75rem`
- When `fullWidth`: `grid-column: 1 / -1`

### PipelineStatus.vue
```typescript
interface Props {
  stage: PipelineStage  // from types/recommendation.ts
}
```
- Maps stage to icon + color + label:
  - `queued` → gray dot, "Queued"
  - `scored` → blue dot, "Scored"
  - `analyzing` → spinning icon, "Analyzing..."
  - `ready` → green check, "Ready"
  - `failed` → red X, "Failed"
- Uses PrimeVue `Tag` component for badge rendering

### ScanProgressCard.vue
```typescript
interface Props {
  phase: string
  current: number
  total: number
  startedAt: Date       // for elapsed time calculation
}
```
- Phase label (e.g., "Scoring")
- PrimeVue `ProgressBar` with `(current/total) * 100` value
- Ticker count: `{current} / {total} tickers`
- Elapsed time: computed from `startedAt` via `setInterval` (1s update)
- Wrapped in `DeskCard` with title "SCAN PROGRESS"
- Cleanup: clear interval on unmount
