# Task: Recommendation detail components

## Description

Build three components that display recommendation details when a ticker is selected: `DeskAssessmentCard.vue` (unified card for any desk assessment), `AgentConsensus.vue` (compact 6-desk summary), and `PositionCard.vue` (contract entry/stop/target/R:R display).

## Acceptance Criteria

- [ ] `DeskAssessmentCard.vue` renders desk name, direction badge, confidence badge, summary, key findings list for any desk type
- [ ] `AgentConsensus.vue` renders compact summary of all 6 desks (direction + confidence per desk) with overall direction/confidence
- [ ] `PositionCard.vue` renders contract description, entry price, stop loss, take profit, R:R ratio, position size, strategy, rationale
- [ ] All prices displayed as formatted strings (never parsed to float)
- [ ] Null/missing fields show `--` fallback
- [ ] All wrapped in `DeskCard` for consistent styling
- [ ] All use `<script setup lang="ts">` with typed props

## Technical Details

### DeskAssessmentCard.vue
```typescript
interface Props {
  assessment: DeskAssessment
}
```
- Header: desk name (capitalized), direction badge, confidence badge
- Body: summary text, bulleted key findings list
- Desk-specific accent colors:
  - trend → blue, volatility → purple, flow → cyan, fundamental → amber, risk → red, contrarian → emerald
- Wrapped in `DeskCard` with title = desk name uppercased (e.g., "TREND")

### AgentConsensus.vue
```typescript
interface Props {
  ticker: string
  assessments: DeskAssessment[]
  overallDirection: string
  overallConfidence: number
}
```
- Header: `{TICKER} — {direction} ({confidence}%)`
- Grid of 6 desk mini-summaries: `[desk icon] [direction ▲/▼/►] [confidence%]`
- 2x3 or 3x2 grid layout depending on space
- Missing desks (< 6) show `--` placeholders
- Wrapped in `DeskCard` with title "AGENT CONSENSUS"

### PositionCard.vue
```typescript
interface Props {
  recommendation: PositionRecommendation
}
```
- Contract description line: e.g., "Buy AAPL 195C 4/18"
- Key-value grid:
  - Entry: `formatPrice(entry_price)`
  - Stop: `formatPrice(stop_loss)` or `--`
  - Target: `formatPrice(take_profit)` or `--`
  - R/R: `{risk_reward_ratio.toFixed(1)}x`
  - Size: `{(position_size_pct * 100).toFixed(0)}%`
  - Strategy: `strategy` or `--`
- Rationale text block below key-values
- All prices use `formatPrice()` from `utils/formatters.ts` — NEVER `parseFloat()`
- Wrapped in `DeskCard` with title "POSITION DETAIL"
