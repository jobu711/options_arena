# Task: API schemas for routing config and cost details

## Description
Add new API schemas to `schemas.py`: `RoutingConfigUpdate` (PUT request body), `RoutingConfigResponse` (resolved config with override flag), `DeskCostDetail` (per-desk cost breakdown). Expand existing `ConfigResponse` with `routing` field and `RecommendationCostSummary` with `desk_details` field.

## Acceptance Criteria
- [ ] `RoutingConfigUpdate` with threshold validators (finite, [0,1], fast < premium), cost validators (non-negative, finite)
- [ ] `RoutingConfigResponse` with `is_override: bool` field
- [ ] `DeskCostDetail` with desk/tier/model/tokens/duration/status fields
- [ ] `ConfigResponse` expanded with `routing: RoutingConfigResponse`
- [ ] `RecommendationCostSummary` expanded with `desk_details: list[DeskCostDetail]`
- [ ] All validators follow NaN defense pattern (isfinite before range check)
- [ ] JSON roundtrip tests pass

## Technical Details
- `RoutingConfigUpdate` replicates `RoutingConfig` validators but lives in `api/schemas.py` (API layer)
- `RoutingConfigResponse` adds `is_override` field to indicate runtime overlay active
- `DeskCostDetail` uses `str` for desk/tier/status (not enums) — API boundary uses strings
- `ConfigResponse` currently has 4 fields (line 755 of schemas.py) — add `routing` as 5th

Files affected:
- `src/options_arena/api/schemas.py`

### Action
1. Add `RoutingConfigUpdate(BaseModel)` with all 6 fields from RoutingConfig + same validators:
   - `enable_model_routing: bool`
   - `complexity_threshold_fast: float` — `math.isfinite()` + `[0.0, 1.0]`
   - `complexity_threshold_premium: float` — same
   - `fast_model: str`
   - `premium_model: str`
   - `cost_per_million_tokens: dict[str, float]` — values finite + non-negative
   - `@model_validator`: `fast < premium`
   - WHY: validates user input at API boundary before constructing RoutingConfig
2. Add `RoutingConfigResponse(BaseModel)` with same 6 fields + `is_override: bool`
   - WHY: response shows current config plus whether it's a runtime override
3. Add `DeskCostDetail(BaseModel)` with `model_config = ConfigDict(frozen=True)`
   - Fields: `desk: str`, `tier: str`, `model_used: str`, `input_tokens: int`, `output_tokens: int`, `duration_ms: int`, `status: str`
   - WHY: per-desk cost breakdown for the cost table
4. Expand `ConfigResponse` with `routing: RoutingConfigResponse`
   - WHY: frontend needs current routing state on dashboard load
5. Expand `RecommendationCostSummary` with `desk_details: list[DeskCostDetail] = []`
   - Default `[]` for pre-migration data with no desk metrics
   - WHY: per-recommendation breakdown for cost table
