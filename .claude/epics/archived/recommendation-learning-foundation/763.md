# Task: Comprehensive tests and edge case coverage

### Edge Cases
- `float("-inf")` rejected (not just `nan` and `+inf`)
- `Prediction` with all context fields None → JSON roundtrip preserves None values
- `AttributionReport` with empty lists → roundtrip preserves empty lists
- `was_correct` None → True → False (re-scoring) preserves latest value
- Zero correct predictions → accuracy = 0.0 (not division by zero)
