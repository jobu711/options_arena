# Task: Neural IV Surface Model

## Description
Implement `IVSurfaceNet(L.LightningModule)` in `pricing/neural_surface.py` — an MLP that maps (log_moneyness, dte_normalized) to implied volatility. Architecture: 3 hidden layers, 64 units each, ReLU + BatchNorm, softplus output (ensures positive IV). Training harness for per-ticker fitting on live chain data. Checkpoint save/load for warm-start on subsequent scans. Add `NeuralConfig` to `MLConfig` and neural-specific feature flags to `ScanConfig`.

## Acceptance Criteria
- [ ] MLP architecture: 2-input, 3x64 hidden (ReLU + BatchNorm), 1-output with softplus
- [ ] Training on (log_moneyness, dte, IV) triples from chain data
- [ ] MSE loss + L2 regularization (weight_decay on optimizer)
- [ ] Checkpoint persistence in `data/model_cache/` (gitignored)
- [ ] Guarded PyTorch import — returns None when `torch`/`lightning` not installed
- [ ] Config flags `enable_neural_surface: bool = False` and `surface_method: Literal["spline", "neural"] = "spline"` on `MLConfig`
- [ ] Public API returns scalar `float` / typed model — PyTorch internals invisible at boundary
- [ ] `math.isfinite()` guards on all outputs

## Technical Details
- Module: `pricing/neural_surface.py` (new file)
- Config: `models/config.py` — extend `MLConfig` with neural fields
- Architecture boundary: `pricing/` uses scalar float in/out, no pandas, no services
- Uses `lightning.LightningModule` for training harness (callbacks, early stopping)
- CPU-first: `accelerator="cpu"` by default, GPU optional
- Checkpoint dir: `data/model_cache/{ticker}_iv_surface.ckpt`
- Guarded import pattern: `_get_torch()` / `_get_lightning()` returning module or None

### Action
1. In `models/config.py`, extend `MLConfig` with neural surface fields:
   - `enable_neural_surface: bool = False`
   - `surface_method: Literal["spline", "neural"] = "spline"` with validator
   - `model_cache_dir: str = "data/model_cache"`
   - `neural_surface_epochs: int = 100` with `[10, 500]` range validator
   - `neural_surface_lr: float = 0.001` with positive finite validator
   - WHY: follows existing MLConfig pattern, all features off by default

2. Create `src/options_arena/pricing/neural_surface.py`:
   - `_get_torch()` / `_get_lightning()` guarded import functions returning module or None
   - `IVSurfaceNet` class (Lightning module) with:
     - `__init__(self, hidden_dim=64, n_layers=3, weight_decay=1e-4)`
     - MLP: Linear(2, 64) -> ReLU -> BN -> Linear(64, 64) -> ReLU -> BN -> Linear(64, 64) -> ReLU -> BN -> Linear(64, 1) -> Softplus
     - `forward(self, x)` — takes (batch, 2) tensor, returns (batch, 1)
     - `training_step(self, batch, batch_idx)` — MSE loss
     - `configure_optimizers()` — Adam with weight_decay (L2 reg)
   - `NeuralSurfaceResult(NamedTuple)` — fitted_ivs, residuals, z_scores, r_squared, is_neural
   - `fit_neural_surface(strikes, ivs, dtes, spot, config)` — public API:
     - Returns `NeuralSurfaceResult | None`
     - Transforms inputs to log_moneyness + sqrt_time
     - Fits model via `lightning.Trainer(max_epochs=N, accelerator="cpu")`
     - Saves checkpoint to `model_cache_dir/{ticker}.ckpt`
     - Returns None when torch unavailable or <30 data points
   - `predict_iv(log_moneyness, dte_normalized, checkpoint_path)` — inference from saved checkpoint
     - Returns `float | None`
   - All public functions: `math.isfinite()` guards, return None on failure
   - WHY: follows pricing module conventions (scalar boundaries, no pandas)

3. Add `data/model_cache/` to `.gitignore`
   - WHY: model checkpoints are per-machine artifacts, not version controlled
