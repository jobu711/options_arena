# Task: LSTM Trajectory Forecasting Model

## Description
Implement `TrajectoryLSTM(L.LightningModule)` in `pricing/trajectory.py` — an LSTM that produces probabilistic price trajectories. Input: 60-day sequence of 8 features (OHLCV + select indicators). Output: per-horizon (mean, std) for lognormal distribution at 30/60/90 DTE. Derive `prob_profit_neural` = P(S_T > strike) from the predicted distribution. Add `prob_profit_neural` field to `MarketContext`. Falls back to BSM lognormal assumption when model unavailable.

## Acceptance Criteria
- [ ] LSTM: 2 layers, 128 hidden, separate `nn.Dropout(0.2)` on output (NOT LSTM internal dropout), 8-feature input
- [ ] Output: (mean, std) at 30/60/90 DTE horizons
- [ ] `prob_profit_neural` = P(S_T > strike) from predicted lognormal distribution
- [ ] Guarded PyTorch import — returns None when `torch`/`lightning` not installed
- [ ] Falls back to BSM lognormal assumption when model unavailable
- [ ] `prob_profit_neural: float | None = None` field on `MarketContext` with `isfinite()` + `[0, 1]` validators
- [ ] Config flag `enable_trajectory: bool = False` on `MLConfig`

## Technical Details
- Module: `pricing/trajectory.py` (new file)
- Model: `models/analysis.py` — add `prob_profit_neural` field to `MarketContext`
- Config: `models/config.py` — add `enable_trajectory` and trajectory hyperparameters to `MLConfig`
- Architecture boundary: `pricing/` returns scalar float, no pandas at public boundary
- Input features: close, high, low, volume, rsi_14, adx, bb_width, atr_pct (8 features, all normalized)
- Output: `TrajectoryForecast` NamedTuple with (mean, std) per horizon
- `prob_profit_neural = 1 - norm.cdf(log(strike/spot), loc=mean, scale=std)` (lognormal CDF)
- LSTM trained per-ticker on historical 60-day windows
- Checkpoint persistence in `data/model_cache/{ticker}_trajectory.ckpt`

### Edge Cases
- Empty feature sequence: returns None
- All-NaN features in sequence: returns None
- Very short sequence (exactly 20): boundary case, may underfit
- Strike at 0: guard against log(0) in prob computation
- Spot at 0: guard against division by zero
- std = 0 from model: degenerate case, prob is 0 or 1

### Mocking Strategy
- `unittest.mock.patch()` on `_get_torch` / `_get_lightning` to simulate missing deps
- `tmp_path` fixture for checkpoint directory
- Synthetic return sequences: known distribution -> verify prob_profit within tolerance
- `scipy.stats.norm.cdf` for ground-truth probability comparison
