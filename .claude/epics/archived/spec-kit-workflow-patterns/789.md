# Task: Add NEEDS CLARIFICATION convention to prd-parse and epic-decompose

## Description

Add `[NEEDS CLARIFICATION: question]` structured placeholder convention with soft gates
at two PM command boundaries: `prd-parse` scans the PRD for requirement ambiguity,
`epic-decompose` scans epic.md for architecture ambiguity. Both gates warn the user and
allow override — they are not hard blocks.

## Acceptance Criteria

- [ ] `prd-parse.md` scans PRD for `[NEEDS CLARIFICATION: ...]` markers before epic creation
- [ ] `prd-parse.md` displays found markers and asks: "N unresolved questions found. Proceed or resolve first?"
- [ ] `epic-decompose.md` scans epic.md for `[NEEDS CLARIFICATION: ...]` markers before task creation
- [ ] `epic-decompose.md` displays found markers and asks same soft-gate question
- [ ] Both gates are user-overridable (soft gates, not hard blocks)
- [ ] Marker format documented: `[NEEDS CLARIFICATION: {specific question}]`
- [ ] Resolution format documented: replace marker + `<!-- Resolved DATE: reason -->` annotation
- [ ] Valid locations documented: `.claude/prds/*.md` and `.claude/epics/*/*.md` only (not Python code)

## Technical Details

### Marker Format

```markdown
**Performance target**: [NEEDS CLARIFICATION: What is the acceptable latency for
a 50-ticker batch recommendation? Current scan takes ~3min for full universe.]
```

### Resolution Format

```markdown
**Performance target**: 60 seconds for 50-ticker batch
<!-- Resolved 2026-03-25: 60s target based on Groq rate limits (30 RPM) -->
```

### Gate Mechanism (identical at both boundaries)

```
Scanning {document_type} for unresolved questions...
Found {N} unresolved NEEDS CLARIFICATION markers:

  1. [NEEDS CLARIFICATION: {question 1}]
     Location: line {N}
  2. [NEEDS CLARIFICATION: {question 2}]
     Location: line {N}

{N} unresolved questions found. Options:
  - Proceed anyway (questions documented but unresolved)
  - Resolve now (provide answers inline)
  - Stop and edit the {PRD/epic} first
```

- `prd-parse` scans the PRD → catches requirement ambiguity (authored by human)
