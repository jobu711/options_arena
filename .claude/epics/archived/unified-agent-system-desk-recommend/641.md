# Task: Add build_cleaned_domain_assessment to _parsing.py

## Description
Add `build_cleaned_domain_assessment()` helper to `agents/_parsing.py`. This function strips `<think>` tags from all string fields of a `DomainAssessment` subclass and returns a cleaned frozen copy. Follows the established `build_cleaned_agent_response()` pattern but uses `model_copy(update=...)` for generic subclass handling.

- [ ] Preserves exact subclass type (e.g., `TrendAssessment` in -> `TrendAssessment` out)

2. Add function `build_cleaned_domain_assessment`:
   ```python
   def build_cleaned_domain_assessment[T: DomainAssessment](output: T) -> T:
       """Strip <think> tags from all string fields of a DomainAssessment subclass."""
       updates: dict[str, object] = {}
       for name, field_info in output.model_fields.items():
           value = getattr(output, name)
           if isinstance(value, str):
               cleaned = strip_think_tags(value)
               if cleaned != value:
                   updates[name] = cleaned
           elif isinstance(value, list) and value and isinstance(value[0], str):
               cleaned_list = [strip_think_tags(item) for item in value]
               if cleaned_list != value:
                   updates[name] = cleaned_list
       if not updates:
           return output
       return output.model_copy(update=updates)  # type: ignore[return-value]
   ```
   - WHY: generic approach handles all subclasses without per-desk logic; `model_copy(update=...)` preserves frozen model pattern

   - WHY: verify all 6 subclasses and all field types handled
