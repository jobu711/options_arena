# Task: Risk + Contrarian desk recommendation agents

## Description
Add recommendation mode to `risk_desk.py` and `contrarian_desk.py`. Each file gains a second `Agent[DeskDeps, *Assessment]` instance that produces a structured `DomainAssessment` subclass. Existing interactive agents are completely untouched. Add `run_*_desk_recommendation()` runner functions.

## Acceptance Criteria
- [ ] `risk_desk.py` has `risk_desk_recommend: Agent[DeskDeps, RiskDeskAssessment]` instance
- [ ] `risk_desk.py` has `run_risk_desk_recommendation()` async runner (never raises)
- [ ] `contrarian_desk.py` has `contrarian_desk_recommend: Agent[DeskDeps, ContrarianAssessment]` instance
- [ ] `contrarian_desk.py` has `run_contrarian_desk_recommendation()` async runner (never raises)
- [ ] Both agents use `model=None` at init, `retries=2`
- [ ] Both agents share same toolset as interactive agent
- [ ] Both agents have `@system_prompt(dynamic=True)` for learned patterns
- [ ] Both agents have `@output_validator` using `build_cleaned_domain_assessment()`
- [ ] Existing interactive desk agents completely unchanged
- [ ] Unit tests for both recommendation agents

## Technical Details
- Files: `src/options_arena/agents/risk_desk.py`, `src/options_arena/agents/contrarian_desk.py`
- Pattern identical to Tasks 643/644 -- only types and prompts differ
- Output types: `RiskDeskAssessment` for risk (NOTE: not `RiskAssessment` -- that's the debate model), `ContrarianAssessment` for contrarian
- Prompts: `RECOMMEND_RISK_PROMPT`, `RECOMMEND_CONTRARIAN_PROMPT`
- Risk fallback: `max_position_pct=0.02`, `hedging_suggestion="Review required"`, `portfolio_correlation_note=None`
- Contrarian fallback: `consensus_challenged=None`, `contrarian_thesis=None`
- IMPORTANT: The risk desk assessment model is `RiskDeskAssessment` (not `RiskAssessment` which is the debate agent model in `models/analysis.py`)
