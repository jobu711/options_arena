# Task: DomainAssessment hierarchy + AnyAssessment discriminated union

## Description

Create the `DomainAssessment` base model and 6 desk-specific subclasses in a new `models/recommendation.py` file. Implement the `AnyAssessment` discriminated union type alias that enables polymorphic JSON round-trip via the `desk` field.

## Acceptance Criteria

- [ ] `DomainAssessment` base model with `frozen=True`, `desk` discriminator field, confidence validator, `isfinite()` guards
- [ ] 6 subclasses: `TrendAssessment`, `VolatilityAssessment`, `FlowAssessment`, `FundamentalAssessment`, `RiskDeskAssessment`, `ContrarianAssessment`
- [ ] Each subclass narrows `desk` to `Literal[DeskType.X]` with default value
- [ ] `AnyAssessment` discriminated union type alias using `Annotated[..., Discriminator("desk")]`
- [ ] JSON round-trip preserves subclass type and domain-specific fields
- [ ] All validators follow NaN defense pattern (`isfinite()` before range check)

## Technical Details

- File: `src/options_arena/models/recommendation.py`
- Uses existing enums: `DeskType`, `SignalDirection`, `VolRegime`, `IVTermStructureShape`, `ValuationSignal`
- Pattern: follows `AgentResponse` frozen model pattern from `analysis.py`
- Discriminated union: Pydantic v2 `Discriminator("desk")` + `Tag()` (Context7-verified in PRD)

### Action

1. Create `src/options_arena/models/recommendation.py` with module docstring
   - WHY: new file for all unified recommendation models (no existing code modified)

2. Define `DomainAssessment` base model with `ConfigDict(frozen=True)`:
   - `desk: DeskType` — discriminator field
   - `direction: SignalDirection`
   - `confidence: float` with `field_validator`: `isfinite()` then `[0.0, 1.0]`
   - `summary: str`
   - `key_factors: list[str]` with non-empty validator
   - `risks: list[str]`
   - `contracts_referenced: list[str]`
   - `tools_used: list[str]`
   - `model_used: str`
   - WHY: base fields shared by all 6 desk assessments per PRD spec

3. Define 6 subclasses, each narrowing `desk` to `Literal[DeskType.X]`:
   - `TrendAssessment`: `trend_strength: float | None = None`, `momentum_signal: str | None = None`
   - `VolatilityAssessment`: `iv_regime: VolRegime | None = None`, `vol_skew_assessment: str | None = None`, `term_structure_shape: IVTermStructureShape | None = None`
   - `FlowAssessment`: `flow_bias: str | None = None`, `unusual_activity_noted: bool = False`
   - `FundamentalAssessment`: `valuation_signal: ValuationSignal | None = None`, `catalyst_timeline: str | None = None`
   - `RiskDeskAssessment`: `max_position_pct: float | None = None`, `hedging_suggestion: str | None = None`, `portfolio_correlation_note: str | None = None`
   - `ContrarianAssessment`: `consensus_challenged: str | None = None`, `contrarian_thesis: str | None = None`
   - WHY: each desk produces domain-specific fields beyond the base assessment

4. Define `AnyAssessment` discriminated union:
   ```python
   AnyAssessment = Annotated[
       Annotated[TrendAssessment, Tag(DeskType.TREND)]
       | Annotated[VolatilityAssessment, Tag(DeskType.VOLATILITY)]
       | Annotated[FlowAssessment, Tag(DeskType.FLOW)]
       | Annotated[FundamentalAssessment, Tag(DeskType.FUNDAMENTAL)]
       | Annotated[RiskDeskAssessment, Tag(DeskType.RISK)]
       | Annotated[ContrarianAssessment, Tag(DeskType.CONTRARIAN)],
       Discriminator("desk"),
   ]
   ```
   - WHY: enables polymorphic deserialization from SQLite JSON storage
