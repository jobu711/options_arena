# Task: Synthesis toolset + synthesis agent module

## Description

Add `build_synthesis_toolset()` to `_toolsets.py` and create `agents/synthesis_agent.py` with `SynthesisDeps`, `synthesis_agent: Agent[SynthesisDeps, PositionRecommendation]`, and `run_synthesis()` never-raises runner. The synthesis agent receives all 6 domain assessments and produces a `PositionRecommendation`.

## Acceptance Criteria

- [ ] `build_synthesis_toolset()` in `_toolsets.py` returns lightweight tools for supplemental lookups
- [ ] `SynthesisDeps` dataclass with `context`, `assessments`, `contracts`, `ticker_score`, `learned_patterns`, `tuned_weights`
- [ ] `synthesis_agent: Agent[SynthesisDeps, PositionRecommendation]` with `model=None`, `retries=2`
- [ ] `@synthesis_agent.system_prompt(dynamic=True)` for learned patterns + tuned weights injection
- [ ] `@synthesis_agent.output_validator` strips think tags
- [ ] `run_synthesis()` wraps agent call with `asyncio.wait_for`, returns fallback on failure
- [ ] `models.ALLOW_MODEL_REQUESTS = False` in test file

## Technical Details

- Files: `src/options_arena/agents/synthesis_agent.py` (new), `src/options_arena/agents/_toolsets.py` (append)
- `SynthesisDeps` is a `@dataclass` (PydanticAI convention, not Pydantic model)
- Synthesis toolset is lightweight: `fetch_quote`, `fetch_option_chain_summary` — desk agents do heavy analysis
- Pattern: follows desk agent pattern (`*_desk.py`) for agent definition + runner
- Runner pattern: `async def run_synthesis(deps, model, settings, config) -> PositionRecommendation`
- Fallback: on any failure, return a data-driven `PositionRecommendation` with `confidence=0.2`

### Action

1. Add `build_synthesis_toolset()` to `_toolsets.py`:
   - 2-3 lightweight tools: `fetch_quote` (reuse existing), `fetch_option_chain_summary` (new)
   - Follow existing tool patterns: `TICKER_RE` validation, `isfinite()` guards, never-raises
   - WHY: synthesis agent may need to verify quotes or check chain liquidity

2. Create `src/options_arena/agents/synthesis_agent.py`:
   - `SynthesisDeps` `@dataclass` with fields from PRD spec
   - `synthesis_agent: Agent[SynthesisDeps, PositionRecommendation]` at module level
   - `model=None`, `retries=2`, `tools=build_synthesis_toolset()`
   - WHY: module-level agent instance enables `TestModel` override pattern

3. Add `@synthesis_agent.system_prompt(dynamic=True)` decorator:
   - Inject `SYNTHESIS_SYSTEM_PROMPT` from `prompts/synthesis.py`
   - Append `<<<TUNED_WEIGHTS>>>` block from `ctx.deps.tuned_weights` if non-empty
   - Append `<<<LEARNED_PATTERNS>>>` block from `ctx.deps.learned_patterns` if non-empty
   - WHY: `dynamic=True` required for runtime-dependent prompt injection

4. Add `@synthesis_agent.output_validator` using `strip_think_tags()`:
   - WHY: Llama 3.x may emit `<think>` tags; strip without costly retry

5. Create `run_synthesis()` async function:
   - Wraps `synthesis_agent.run()` with `asyncio.wait_for(timeout=config.synthesis_timeout)`
   - On any exception: log warning, return fallback `PositionRecommendation`
   - Fallback: `confidence=0.2`, `direction=SignalDirection.NEUTRAL`, template values
   - WHY: never-raises contract — synthesis failure must not crash the pipeline
