# Task: Create recommendation_orchestrator.py — run_recommendation() pipeline

## Description
Create `agents/recommendation_orchestrator.py` with the `run_recommendation()` function
that implements the 3-phase recommendation pipeline: Phase 0 (context building), Phase 1
(parallel desk recommendation agents), Phase 2 (synthesis agent), Phase 3 (persistence).
Includes `RecommendationProgressCallback` type alias, `desk_parallelism` config on
`AgencyConfig`, and fallback handling for partial/full desk failures.

- [ ] `recommendation_orchestrator.py` exists with `run_recommendation()` function

- [ ] Never-raises contract: all exceptions caught → fallback `RecommendationResult`
- [ ] Parallel desk execution via `asyncio.gather(return_exceptions=True)` with `Semaphore`

### Phase 0: Build Context
- Call `build_market_context()` from `_context.py` to build `MarketContext`
- Check `should_recommend()` — if False, return early with low-confidence fallback
- Build `DeskDeps` with scan data (ticker_score, contracts, market_context)
- Build model via `build_debate_model()`, build model settings via `_build_model_settings()`
- Fetch learned patterns and tuned weights from repo (never-raises)

### Phase 1: Parallel Desk Recommendations
- Run all 6 desk recommendation runners in parallel:
  - `run_trend_desk_recommendation()`
  - `run_vol_desk_recommendation()`
  - `run_flow_desk_recommendation()`
  - `run_fundamental_desk_recommendation()`
  - `run_risk_desk_recommendation()`
  - `run_contrarian_desk_recommendation()`
- Gate with `asyncio.Semaphore(settings.agency.desk_parallelism)` (default 6)
- `asyncio.gather(*tasks, return_exceptions=True)` — exceptions become fallback assessments
- Each desk's runner already has never-raises contract — but double-guard anyway

### Phase 2: Synthesis
- Build `SynthesisDeps` with all assessments (real + fallback), contracts, context
- Call `run_synthesis()` with model and model_settings
- If synthesis fails → build fallback `PositionRecommendation` from majority assessment direction

### Phase 3: Persist
- Save `RecommendationResult` via `repo.save_recommendation()`
- Extract `AgentPrediction` list with `recommendation_protocol='recommend_v1'`
- Save predictions via `repo.save_agent_predictions()`
- Persistence errors logged but never raised

- `repo=None` not supported (repo is required parameter)
