# Task: Wire Phase 3 indicators (Groups C/D)

## Description

Connect 10 existing indicator functions to the Phase 3 scan pipeline in `compute_phase3_indicators()`. These functions are fully implemented and tested but never called. Groups C (require option chain data) and D (require vol surface data) have all necessary data available in Phase 3.

## Acceptance Criteria

- [ ] All 10 indicator functions wired into `compute_phase3_indicators()` in `scan/indicators.py`
- [ ] Each result mapped to its `IndicatorSignals` field
- [ ] Non-finite results guarded with `math.isfinite()` + try/except
- [ ] `put_call_ratio_oi` has a new `IndicatorSignals` field (none exists currently for OI-based ratio)
- [ ] `detect_flow_anomalies` result unwrapped from `FlowAnomalyResult.anomaly_score`
- [ ] Integration tests verify each indicator is populated with valid input data
- [ ] All indicators return None gracefully when data is missing

### Special handling required

1. **`detect_flow_anomalies`**: Returns `FlowAnomalyResult | None`, not `float | None`. Must unwrap: `result.anomaly_score if result else None`
2. **`put_call_ratio_oi`**: Returns `float` (NaN on divide-by-zero). No dedicated field exists on `IndicatorSignals` — need to add `put_call_ratio_oi: float | None = None` field. Also add DOMAIN_BOUNDS and optionally INDICATOR_WEIGHTS entry
3. **`compute_pop`**: Needs BSM `d2` value — must compute from contract Greeks or call BSM helper. Check if `d2` is available from existing Phase 3 context
4. **`compute_max_loss_ratio`**: Needs `account_risk_budget` parameter not available in pipeline — may need to use a config default or skip
5. **Group D skew indicators**: Need IV at 25-delta put/call and ATM from vol surface. The `vol_result: VolSurfaceResult` parameter in `compute_phase3_indicators()` may provide this data

### Data availability in Phase 3
`compute_phase3_indicators()` receives:
- `contracts: list[OptionContract]` — has bid, ask, volume, open_interest, implied_vol, theta, delta
- `spot: float` — current stock price
- `close_series: pd.Series` — historical close prices
- `vol_result: VolSurfaceResult | None` — fitted vol surface with ATM IV, skew params
