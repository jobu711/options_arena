# Task: Modernize DebatePhase enum and wire progress callback

## Description

Replace the legacy 5-member `DebatePhase` enum (BULL, BEAR, REBUTTAL, VOLATILITY, RISK) with 6 members matching the current 6-agent protocol (TREND, VOLATILITY, FLOW, FUNDAMENTAL, RISK, CONTRARIAN). Wire the `_progress` callback in `_run_debate_pipeline()` to emit per-agent progress events. Update WebSocket bridge to handle new enum values.

## Acceptance Criteria

- [ ] `DebatePhase` has exactly 6 members: TREND, VOLATILITY, FLOW, FUNDAMENTAL, RISK, CONTRARIAN
- [ ] `_progress` callback invoked before each agent run with `(phase, "running", None)`
- [ ] `_progress` callback invoked after each agent run with `(phase, "complete", confidence)`
- [ ] WebSocket events emit correct phase names (e.g., `"name": "trend"` instead of `"name": "bull"`)
- [ ] Frontend (Vue) handles new phase names — update if needed
- [ ] `DebateProgressCallback` type alias unchanged (still `Callable[[DebatePhase, str, float | None], None]`)
- [ ] Tests updated for new enum members

### Progress callback wiring
In `_run_debate_pipeline()`, rename `_progress` to `progress` and add calls:
```python
# Before trend agent
if progress:
    progress(DebatePhase.TREND, "running", None)
trend_output = await trend_agent.run(...)
if progress:
    progress(DebatePhase.TREND, "complete", trend_output.data.confidence)
```
Repeat for each of the 6 agents.

### WebSocket impact
`DebateProgressBridge.__call__()` (ws.py line 113) and `_BatchAgentBridge.__call__()` (ws.py line 151) use `phase.value` as the `"name"` field. No code change needed in ws.py — the bridge transparently forwards whatever `phase.value` is. The wire values will change from `"bull"/"bear"/"rebuttal"` to `"trend"/"flow"/"fundamental"/"contrarian"`.

### Frontend impact
Check `web/src/` for hardcoded references to `"bull"`, `"bear"`, `"rebuttal"` in WebSocket message handling. Update to match new values. The frontend may need to update:
- Agent name display logic
- Progress indicator component
- Any mapping of phase names to icons/colors
