# Task: Delete IntelligenceService + models

## Description

Delete the `IntelligenceService` class (583 lines) and all intelligence models (414 lines).
The service is instantiated in `api/app.py` but `recommendation_orchestrator.py` never passes
the `intelligence=` kwarg to `build_market_context()` — data never reaches any analysis path.
Also delete all associated test files and remove the service re-export from `services/__init__.py`.

- `IntelligenceService(ServiceBase[IntelligenceConfig])` — 6 fetch methods + 1 aggregator
- 7 frozen snapshot models: `AnalystSnapshot`, `UpgradeDowngrade`, `AnalystActivitySnapshot`,

- Service uses yfinance data via `asyncio.to_thread`, cache-first with TTL, never-raises contract
