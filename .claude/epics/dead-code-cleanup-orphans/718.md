# Task: Remove IntelligenceConfig from settings + lifespan wiring

## Description

Remove all remaining infrastructure that supported `IntelligenceService`: the
`IntelligenceConfig` class from settings, the lifespan wiring in `api/app.py`, the
dependency provider in `api/deps.py`, the `intelligence=` parameter from
`render_combined_context()` in `agents/_context.py`, and intelligence model re-exports
from `models/__init__.py`.

- [ ] `IntelligenceConfig` class removed from `models/config.py` (lines ~465-507)

- [ ] Intelligence dependency provider removed from `api/deps.py` (if exists)

## Technical Details

- `IntelligenceConfig(BaseModel)` has 11 fields: `enabled`, per-source toggles, timeouts, TTLs
- `AppSettings.intelligence: IntelligenceConfig = IntelligenceConfig()` — nested config
- `api/app.py` lifespan: conditionally creates `IntelligenceService`, stores on `app.state.intelligence`
- `agents/_context.py`: `render_combined_context(..., intelligence: IntelligencePackage | None = None, ...)`
  uses the package to render analyst/insider/institutional context into agent prompts (lines 204-240)
- `models/__init__.py` re-exports 7 intelligence models + `IntelligencePackage`
