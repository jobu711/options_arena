## Description

Delete the entire `api/routes/learning.py` file (148 lines, 7 endpoints) and remove its

## Technical Details

All 7 endpoints being removed:
- `GET /api/learning/weights` — current weight snapshots
- `GET /api/learning/weights/history` — historical snapshots
- `GET /api/learning/status` — learning system status
- `POST /api/learning/weights/tune` — trigger indicator weight tuning
- `POST /api/learning/mine` — trigger strategy pattern mining
- `GET /api/learning/playbook` — list strategy rules
- `PUT /api/learning/playbook/{rule_id}` — update rule status

These are all wrappers around `learning/` module functions. The CLI commands call the same
underlying functions directly and remain functional.
