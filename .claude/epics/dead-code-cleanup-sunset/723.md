## Technical Details

### Code being extracted (lines 563–645)

1. **Early earnings check** (563–581): Fetch earnings date, check if within
   `exclude_near_earnings_days`, return empty tuple if filtered.
2. **Concurrent data fetch** (583–606): `asyncio.gather` of chain_task, info_task,
   and optionally earnings_task. Re-raise on chain/info failures.
3. **Market cap tier filter** (608–620): Check `universe_filters.market_cap_tiers`.
4. **Metadata enrichment** (622–634): Enrich `ticker_score.company_name`, upsert
   metadata to repository.
5. **Contract flattening** (636–645): Flatten all expirations into single list.

### Return type design

```python
@dataclass(frozen=True)
class _TickerData:
    """Result of per-ticker data fetching in Phase 3."""
    all_contracts: list[OptionContract]
    ticker_info: TickerInfo
    earnings_date: date | None
    entry_stock_price: Decimal | None
    filtered_out: bool  # True if ticker was filtered (earnings or market cap)
```

When `filtered_out` is True, `all_contracts` will be empty and the caller should
return early with the empty result tuple.

### Parameters

The helper needs: `ticker_score`, `risk_free_rate` (unused but kept for
consistent interface), `market_data`, `options_data`, `repository`,
`options_filters`, `universe_filters`, `recommend_contracts_fn` (unused, omit),
`map_yfinance_fn`.
