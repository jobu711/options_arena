# Task: Extract `_compute_dse_indicators` helper from `process_ticker_options`

## Description

Extract the DSE indicator computation block (lines 649–734 of `phase_options.py`)
into a standalone `_compute_dse_indicators()` helper. This block handles:
options-specific indicators (put/call ratio, max pain), vol surface computation,
Phase 3 DSE indicators via `compute_phase3_indicators()`, signal merging, and
IV rank filtering. After extraction, update `process_ticker_options` to call the
new helper.

## Technical Details

### Code being extracted (lines 649–734)

1. **Options-specific indicators** (649–657): `compute_options_indicators()` →
   merge `put_call_ratio` and `max_pain_distance` into `ticker_score.signals`.
   Also computes `mp_strike` via `_extract_mp_strike()`.
2. **Vol surface computation** (660–695): Convert OHLCV → DataFrame, build
   strike/IV/DTE/type arrays, call `compute_vol_surface()`.
3. **Phase 3 DSE indicators** (697–711): Call `compute_phase3_indicators()` with
   all context, merge via `_merge_signals()`.
4. **IV rank filter** (724–734): Check `options_filters.min_iv_rank` against
   the newly-populated `iv_rank` field. Return early if filtered.

### Return type design

```python
@dataclass(frozen=True)
class _DSEResult:
    """Result of Phase 3 DSE indicator computation."""
    vol_result: VolSurfaceResult | None
    vs_strikes: np.ndarray | None
    vs_dtes: np.ndarray | None
    mp_strike: float | None
    iv_filtered_out: bool  # True if iv_rank < min_iv_rank
```

Signals are mutated in place on `ticker_score.signals` (same as current).
The returned `vol_result`, `vs_strikes`, `vs_dtes` are needed by the
contract selection step downstream.

`earnings_date`, `risk_free_rate`, `options_filters`, `surface_method`, `ml_config`.
