## Technical Details

### Block 1: `_select_and_score_contracts` (lines 736–795)

**Inputs**: `all_contracts`, `ticker_score`, `spot`, `risk_free_rate`,
`ticker_info.dividend_yield`, `options_filters`, `pricing_config`,
`vol_result`, `vs_strikes`, `vs_dtes`, `recommend_contracts_fn`.

**Logic**:
1. Build `_surface_residuals` dict from `vol_result.z_scores` matched to contracts
2. Call `_recommend(contracts, direction, spot, ...)` → `list[OptionContract]`
3. If recommended and vol_result available, compute `surface_indicators` for
   first recommended contract → merge `iv_surface_residual`, `surface_fit_r2`,
   `surface_is_1d` into `ticker_score.signals`

**Returns**: `list[OptionContract]` (the recommended contracts).

### Block 2: `_build_spread` (lines 797–848)

**Inputs**: `all_contracts`, `recommended`, `ticker_score`, `spot`,
`risk_free_rate`, `ticker_info.dividend_yield`, `options_filters`,
`spread_config`.

**Logic**:
1. Guard: skip if `spread_config` is None/disabled or no contracts
2. Determine target expiration from recommended[0] or closest to max_dte
3. Filter contracts to single expiration (1-day tolerance)
4. Call `select_strategy(...)` → `SpreadAnalysis | None`

**Returns**: `SpreadAnalysis | None`.
