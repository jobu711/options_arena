## Technical Details

### AttributionPanel.vue
```typescript
const windowDays = ref(90)
const report = ref<AttributionReport | null>(null)
const loading = ref(false)

async function fetchAttribution(): Promise<void> {
  loading.value = true
  try {
    report.value = await api<AttributionReport>(
      '/api/analytics/attribution',
      { params: { window_days: windowDays.value } }
    )
  } finally {
    loading.value = false
  }
}
```

Three sections:
1. **Source Accuracy Table**: PrimeVue DataTable with columns: source, total, correct, accuracy%, sample_sufficient badge
2. **Condition Buckets**: grouped by source, showing condition name, accuracy, sample size
3. **Contract Guidance** (if present): optimal delta range, optimal DTE range, win rates, sample count
