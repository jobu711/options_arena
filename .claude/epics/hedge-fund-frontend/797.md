# Task: OpportunityTable component

## Description

Build the `OpportunityTable.vue` component — the core pipeline table showing all scanned tickers with composite score, direction, confidence, sector, stage badge, and action buttons. Features PrimeVue DataTable with virtual scroll for >1000 rows, multi-select checkboxes, sortable columns, and inline filtering. Spans full grid width.

## Acceptance Criteria

- [ ] PrimeVue DataTable renders columns: checkbox, ticker, score, direction, confidence, sector, stage, action
- [ ] Virtual scroll enabled when >1000 rows (`scrollable`, `scrollHeight`, `virtualScrollerOptions`)
- [ ] Multi-select checkboxes with header select-all
- [ ] Sortable by score (default desc), direction, confidence, stage
- [ ] "Analyze" button on each scored row; "View" button on ready rows
- [ ] Stage column uses `PipelineStatus.vue` badge
- [ ] Direction column uses existing `DirectionBadge.vue`
- [ ] Confidence column shows percentage with monospace font
- [ ] Wrapped in `DeskCard` with title "OPPORTUNITY PIPELINE" and ticker count, `fullWidth: true`
- [ ] Row click selects ticker (emits event for detail panel)
- [ ] Selected row highlighted

## Technical Details

### Component structure
```typescript
interface Props {
  tickers: PipelineTicker[]
}

const emit = defineEmits<{
  selectTicker: [ticker: string]
  analyzeTicker: [ticker: string]
  selectionChange: [tickers: string[]]
}>()

const selectedRows = ref<PipelineTicker[]>([])
```

### DataTable configuration
```vue
<DataTable
  :value="tickers"
  v-model:selection="selectedRows"
  @row-click="onRowClick"
  @selection-change="onSelectionChange"
  sortMode="single"
  sortField="composite_score"
  :sortOrder="-1"
  :scrollable="true"
  scrollHeight="flex"
  :virtualScrollerOptions="tickers.length > 1000 ? { itemSize: 44 } : undefined"
  dataKey="ticker"
  :rowClass="rowClass"
>
```

### Columns
| Column | Field | Sortable | Template |
|--------|-------|----------|----------|
| Checkbox | selection | N/A | PrimeVue selection column |
| Ticker | ticker | Yes | Bold monospace text |
| Score | composite_score | Yes | `score.toFixed(1)` monospace |
| Direction | direction | Yes | `DirectionBadge` component |
| Confidence | direction_confidence | Yes | `${(conf * 100).toFixed(0)}%` or `--` |
| Sector | sector | Yes | Plain text, `--` if null |
| Stage | stage | Yes | `PipelineStatus` component |
| Action | — | No | "Analyze" (scored) / "View" (ready) / spinner (analyzing) |

### Row highlighting
- Selected row: `background: var(--p-surface-700)` via `:rowClass`
- Ready rows: subtle left border accent
