# Task: Router & App shell rewrite

## Description

Rewrite the Vue Router from 8 routes to 3 routes (trading-desk, analytics, settings placeholder) and rewrite `App.vue` from a multi-page nav shell to a minimal trading desk layout with a slim top bar.

## Acceptance Criteria

- [ ] `router/index.ts` defines exactly 3 routes: `/` (TradingDeskPage), `/analytics` (AnalyticsPage), `/settings` (placeholder)
- [ ] All routes use lazy loading (`() => import(...)`)
- [ ] `App.vue` has minimal top bar: logo/title, 2-3 nav links, health dot
- [ ] `App.vue` content area is full-height (`flex: 1`, no extra padding/margin)
- [ ] Toast host preserved for notifications
- [ ] Health store fetch on mount preserved
- [ ] `npm run build` succeeds (with placeholder page components if needed)

## Technical Details

### Router rewrite
```typescript
const routes: RouteRecordRaw[] = [
  { path: '/', name: 'trading-desk', component: () => import('../pages/TradingDeskPage.vue') },
  { path: '/analytics', name: 'analytics', component: () => import('../pages/AnalyticsPage.vue') },
  { path: '/settings', name: 'settings', component: () => import('../pages/SettingsPage.vue') },
  { path: '/:pathMatch(.*)*', redirect: '/' },  // catch-all redirect
]
```

### App.vue rewrite
- Slim top bar: `OPTIONS ARENA` title (monospace, tracking), nav links styled as tabs, HealthDot in corner
- Full-height main content: `display: flex; flex-direction: column; height: 100vh`
- Keep `ToastService` host
- Keep `onMounted` health fetch + operation sync
- Dark theme background: `var(--p-surface-950)` or similar

### Placeholder pages
Create minimal stub files for pages that don't exist yet:
- `pages/TradingDeskPage.vue` — `<template><div>Trading Desk (coming soon)</div></template>`
- `pages/SettingsPage.vue` — `<template><div>Settings (V2)</div></template>`

These stubs ensure the build passes. Later tasks fill in the real content.
