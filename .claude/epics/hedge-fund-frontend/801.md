# Task: ScanControlBar component

## Description

Build the `ScanControlBar.vue` component — the top control bar of the trading desk with preset selector, collapsible filter panel, Run Scan / Cancel buttons, and Analyze Selected button. Integrates existing `PreScanFilters.vue` and `FilterPresets.vue` components.

## Acceptance Criteria

- [ ] Preset dropdown selector using existing `PresetCard.vue` / `FilterPresets.vue`
- [ ] Collapsible filter panel toggle that reveals `PreScanFilters.vue`
- [ ] "Run Scan" button triggers scan via pipeline store; disabled during active scan
- [ ] "Cancel" button visible only during active scan; sends cancel via WS
- [ ] "Analyze Selected" button visible when rows selected; triggers batch analysis
- [ ] "Analyze Top N" button as secondary action when no rows selected
- [ ] Live status indicator showing scan phase during active scan
- [ ] Wrapped in `DeskCard` with title "SCAN CONTROL"
- [ ] `<script setup lang="ts">` with typed props/emits

## Technical Details

### Component structure
```typescript
// No external props — reads state from pipeline store
const pipelineStore = usePipelineStore()
const scanStore = useScanStore()

// Local state
const showFilters = ref(false)
const filterPayload = ref<PreScanFilterPayload>({})

// Computed
const isScanning = computed(() => pipelineStore.phase === 'scanning')
const canAnalyze = computed(() => selectedCount.value > 0 && !isScanning.value)
```

### Emits
```typescript
const emit = defineEmits<{
  analyzeSelected: []
  analyzeTopN: [limit: number]
}>()
```

### Layout
- Horizontal bar: `[Preset ▾] [Filters ▾] [▶ Run Scan | ■ Cancel] [Analyze Selected (N)] [Analyze Top 5 ▾]`
- Below bar: collapsible `PreScanFilters` panel (slides down when "Filters" toggled)
- Uses PrimeVue `Button`, `Select` (dropdown) components
- "Analyze Selected" shows count badge: `Analyze Selected (3)`

### Integration with existing filter components
- `PreScanFilters.vue` already emits a `PreScanFilterPayload`
- `FilterPresets.vue` / `PresetCard.vue` handle preset selection
- Wire their events to the local `filterPayload` and pass to `pipelineStore.startScan()`
