# Task: Update desk runners to return RunUsage

## Description
Update all 6 desk recommendation runner functions to return `tuple[DomainAssessment, RunUsage]` instead of just `DomainAssessment`. Currently, each `run_*_desk_recommendation()` function calls `agent.run()`, extracts `result.output`, and discards the `RunResult` (which contains `result.usage()` with actual token counts). This change preserves the usage data so the orchestrator can populate `DeskMetrics` with real token counts.

## Acceptance Criteria
- [ ] All 6 desk runner functions return `tuple[Assessment, RunUsage]`
- [ ] Success path returns `(cleaned_assessment, result.usage())`
- [ ] Fallback/timeout paths return `(fallback_assessment, RunUsage())` (empty usage)
- [ ] Type annotations updated on all 6 functions
- [ ] No changes to agent definitions, prompts, or tool wrappers
- [ ] `mypy --strict` passes on all 6 files

## Technical Details
- Each desk has a `run_*_desk_recommendation()` function that wraps `agent.run()`
- PydanticAI `RunResult` has a `.usage()` method returning `RunUsage` (with `input_tokens`, `output_tokens` fields)
- The return type change must be consistent across all 6 desks
- Import `RunUsage` from `pydantic_ai.usage`

Files affected:
- `src/options_arena/agents/trend_desk.py`
- `src/options_arena/agents/volatility_desk.py`
- `src/options_arena/agents/flow_desk.py`
- `src/options_arena/agents/fundamental_desk.py`
- `src/options_arena/agents/risk_desk.py`
- `src/options_arena/agents/contrarian_desk.py`
