# Task: Frontend types + ModelRoutingPanel component

## Description
Add TypeScript interfaces for routing config and cost details. Create `ModelRoutingPanel.vue` — a collapsible PrimeVue `Panel` on the Dashboard with: ToggleSwitch (enable/disable), Slider (thresholds), InputText (model names), InputNumber (cost map), Apply and Reset buttons.

## Acceptance Criteria
- [ ] TypeScript interfaces: `RoutingConfig`, `DeskCostDetail`, `RecommendationCostDetail` in `types/config.ts`
- [ ] `ConfigResponse` interface expanded with `routing: RoutingConfig`
- [ ] `ModelRoutingPanel.vue` with collapsible Panel, all form controls, Apply/Reset buttons
- [ ] Apply sends PUT `/api/config/routing` with current form values
- [ ] Reset sends DELETE `/api/config/routing` and refreshes form
- [ ] Client-side validation: fast < premium thresholds, non-negative costs
- [ ] Loading states on Apply/Reset buttons
- [ ] Toast notifications on success/error
- [ ] `<script setup lang="ts">` with Composition API

## Technical Details
- Use PrimeVue `Panel toggleable` for collapsible card (Context7-verified)
- Use `ToggleSwitch` for enable/disable (Context7-verified)
- Use `Slider` with `:min="0"` `:max="1"` `:step="0.05"` for thresholds
- Use `InputText` for model names (fast_model, premium_model)
- Use `InputNumber` with `:min="0"` `:maxFractionDigits="4"` for cost values
- Cost map editor: iterate over `Object.entries(cost_per_million_tokens)` with delete/add buttons
- Use `useApi` composable for API calls (never raw fetch)
- Use `useToast()` for notifications

Files affected:
- `web/src/types/config.ts` (expand)
- `web/src/components/ModelRoutingPanel.vue` (new)

2. Expand `ConfigResponse` with `routing: RoutingConfig`
   - WHY: GET /api/config now returns routing state
3. Create `ModelRoutingPanel.vue` with `<script setup lang="ts">`:
   - Props: `initialConfig: RoutingConfig`

   - Reset handler: DELETE → toast → emit 'updated'
   - WHY: collapsible settings card for the dashboard
4. Form layout:
   - ToggleSwitch for `enable_model_routing`
   - Two Sliders for thresholds with labels showing current value
   - InputText fields for fast_model and premium_model
   - Cost map: list of key-value pairs with InputText (model name) + InputNumber (cost)
   - "Add Model" button to add new cost entry
   - Apply + Reset to Defaults buttons
   - WHY: full control over all routing config fields
