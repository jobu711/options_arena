# Task: Frontend RecommendationCostTable + DashboardPage integration

## Description
Create `RecommendationCostTable.vue` — a DataTable showing recent recommendations with per-desk cost breakdowns. Integrate both `ModelRoutingPanel` and `RecommendationCostTable` into `DashboardPage.vue`.

## Acceptance Criteria
- [ ] `RecommendationCostTable.vue` displays recent recommendations with expandable per-desk rows
- [ ] Top-level columns: ticker, timestamp, total tokens, estimated cost, fallback badge
- [ ] Expanded rows show: desk, tier badge, model, input/output tokens, duration, status badge
- [ ] Empty state message when no recommendations exist
- [ ] `DashboardPage.vue` loads routing config and cost data on mount
- [ ] `ModelRoutingPanel` 'updated' event triggers cost table refresh
- [ ] Both components in collapsible sections on the dashboard

## Technical Details
- Use PrimeVue `DataTable` with row expansion (`v-model:expandedRows`) for per-desk details
- Tier badges: colored Tags (green=FAST, blue=STANDARD, purple=PREMIUM)
- Status badges: green=SUCCESS, yellow=FALLBACK
- Cost formatting: `$X.XXXX` (4 decimal places for small costs)
- Token formatting: thousands separator via `Intl.NumberFormat`
- Fetch cost data from `GET /api/analytics/recommendation-costs?limit=10`
- Cost table refreshes when ModelRoutingPanel emits 'updated'

Files affected:
- `web/src/components/RecommendationCostTable.vue` (new)
- `web/src/pages/DashboardPage.vue` (integrate both components)
