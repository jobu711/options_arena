# Task: Attribution computation and condition classifiers

## Description

Add attribution computation to `learning/prediction_ledger.py`: per-source accuracy
grouping, condition bucket classifiers (ADX, IV Rank, ATR%, RSI), condition-level
accuracy computation, and the top-level `compute_attribution()` function that produces
an `AttributionReport`. Enforces minimum sample thresholds.

## Acceptance Criteria

- [ ] `compute_attribution(predictions, contract_guidance=None) -> AttributionReport` function
- [ ] `_classify_adx(adx) -> str | None` — weak/moderate/strong buckets
- [ ] `_classify_iv_rank(iv_rank) -> str | None` — low/mid/high buckets
- [ ] `_classify_atr_pct(atr_pct) -> str | None` — low/medium/high buckets
- [ ] `_classify_rsi(rsi) -> str | None` — oversold/neutral/overbought buckets
- [ ] Source-level accuracy: min 10 samples for `sample_sufficient=True`
- [ ] Condition-level accuracy: min 20 samples per bucket
- [ ] Returns empty lists (not errors) when no scored predictions exist
- [ ] Unit tests for all classifiers and attribution logic pass

## Technical Details

- Classifiers follow `strategy_book.py` pattern: list of `(low, high, label)` tuples
- ADX: `<20` weak, `20-30` moderate, `>30` strong
- IV Rank: `<30` low, `30-70` mid, `>70` high
- ATR%: `<1.5` low, `1.5-3.0` medium, `>3.0` high
- RSI: `<30` oversold, `30-70` neutral, `>70` overbought
- None values → excluded from that dimension's bucketing
- `compute_attribution()` is a pure function (no DB access) — takes pre-fetched predictions list

   ```python

   IV_RANK_BUCKETS: list[tuple[float, float, str]] = [(0, 30, "low"), (30, 70, "mid"), (70, 100, "high")]
   ATR_PCT_BUCKETS: list[tuple[float, float, str]] = [(0, 1.5, "low"), (1.5, 3.0, "medium"), (3.0, 100, "high")]
   RSI_BUCKETS: list[tuple[float, float, str]] = [(0, 30, "oversold"), (30, 70, "neutral"), (70, 100, "overbought")]
   ```
   - WHY: consistent with `strategy_book.py` bucket pattern, easy to adjust thresholds
2. Add `_classify_adx()`, `_classify_iv_rank()`, `_classify_atr_pct()`, `_classify_rsi()`:
   - Input `float | None` → return `str | None`
   - None input → None return (excluded from bucketing)
   - WHY: condition slicing for attribution (US-2)
3. Add `_compute_source_accuracy(predictions) -> list[PredictionAccuracy]`:
   - Group by `source`, count total/correct for scored predictions
   - `sample_sufficient = total >= MIN_SOURCE_SAMPLES` (10)
   - WHY: per-source accuracy is the core attribution metric
4. Add `_compute_condition_accuracy(predictions) -> list[ConditionBucketAccuracy]`:
   - For each prediction, classify all 4 dimensions
   - Group by `(source, condition_label)`, compute accuracy
   - Skip groups with `total < MIN_CONDITION_SAMPLES` (20)
   - WHY: condition slicing reveals when desks work well vs. poorly (US-2)
5. Add `compute_attribution(predictions, contract_guidance=None) -> AttributionReport`:
   - Filter to scored predictions (`was_correct is not None`)
   - Call source and condition accuracy helpers
   - Count totals from full list (including unscored)
   - WHY: top-level pure function, testable without DB
