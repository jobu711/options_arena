# Task: Hook scoring into outcomes collect

## Description

Wire prediction scoring into the outcome collection flow so predictions are automatically
scored when outcomes are collected (US-6). After `collector.collect_outcomes()` returns,
call `run_prediction_scoring(repo)` before confidence decay. No additional user action
required — scoring happens as part of the existing `outcomes collect` command.

## Acceptance Criteria

- [ ] `run_prediction_scoring(repo)` called after outcome collection in `_outcomes_collect_async()`
- [ ] Scoring runs before `run_confidence_decay()` (predictions scored first, then decay applies)
- [ ] Scoring failure (exception) doesn't block outcome collection or confidence decay
- [ ] Log message confirms scoring ran: "Scored N predictions"
- [ ] Unit test verifies hook is called in correct order

## Technical Details

- Hook location: `cli/outcomes.py`, `_outcomes_collect_async()` function, after line ~90 where `collector.collect_outcomes()` returns
- Import `run_prediction_scoring` from `learning.prediction_ledger`
- `run_prediction_scoring()` is already never-raises (Task 765), so no extra try/except needed
- Order matters: collect → score predictions → confidence decay
