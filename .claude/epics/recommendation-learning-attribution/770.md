# Task: Attribution CLI command and API endpoint

## Description

Add `learn attribution` CLI subcommand to `cli/agency.py` and `GET /api/analytics/attribution`
endpoint to `api/routes/analytics.py`. Both display per-source accuracy with condition
bucketing from the `AttributionReport`. CLI uses Rich tables. API returns typed JSON.
Delivers US-1 and US-2 user-facing surfaces.

## Acceptance Criteria

- [ ] `learn attribution [--window-days 90] [--source desk_trend]` CLI command
- [ ] Rich table output: source accuracy with sample counts and sufficiency flag
- [ ] Condition breakdown table (when data exists)
- [ ] `GET /api/analytics/attribution?window_days=90&source=desk_trend` API endpoint
- [ ] Returns `AttributionReport` JSON
- [ ] Rate limited at 60/minute
- [ ] Empty data → "No scored predictions found" message (not crash)
- [ ] Unit tests for both surfaces pass

## Technical Details

- CLI: `learn_app` is in `cli/agency.py` (~line 259). Add `@learn_app.command("attribution")`
- CLI pattern: sync Typer command, `asyncio.run()` for async work, Rich table output
- API: router in `api/routes/analytics.py` (~line 37). Add `@router.get("/attribution")`
- API pattern: `@limiter.limit("60/minute")`, `Request` param, `Depends(get_repo)`
- Both call `compute_attribution()` with predictions from `repo.get_predictions()`
- `PredictionSource` enum as optional filter parameter

### Action
1. In `src/options_arena/cli/agency.py`, add `@learn_app.command("attribution")`:
   ```python
   @learn_app.command("attribution")
   def attribution_cmd(
       window_days: int = typer.Option(90, min=7, max=365, help="Lookback window in days"),
       source: PredictionSource | None = typer.Option(None, help="Filter to single source"),
   ) -> None:
       """Show prediction accuracy by source and market condition."""
       asyncio.run(_run_attribution(window_days, source))
   ```
   - WHY: follows existing `learn status`/`learn weights` pattern — sync wrapper + async inner
2. Add `async def _run_attribution(window_days, source)`:
   - Create repo, fetch predictions with `repo.get_predictions(window_days, source)`
   - Call `compute_attribution(predictions)`
   - Display Rich table with columns: Source, Total, Correct, Accuracy, Sufficient
   - If condition accuracy exists, display second table: Source, Condition, Accuracy, Samples
   - If no scored predictions: `console.print("No scored predictions found in the last {window_days} days.")`
   - WHY: async for DB access, Rich tables for readability
3. In `src/options_arena/api/routes/analytics.py`, add `@router.get("/attribution")`:
   ```python
   @router.get("/attribution")
   @limiter.limit("60/minute")
   async def get_attribution(
       request: Request,
       window_days: int = Query(default=90, ge=7, le=365),
       source: PredictionSource | None = Query(default=None),
       repo: Repository = Depends(get_repo),
   ) -> AttributionReport:
       predictions = await repo.get_predictions(window_days, source)
       return compute_attribution(predictions)
   ```
   - WHY: follows existing endpoint pattern, returns typed model, rate limited
4. Add imports in both files: `PredictionSource`, `compute_attribution`, `AttributionReport`
   - WHY: type annotations and function calls
