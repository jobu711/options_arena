# Task: Integration tests and full-loop verification

## Description

Write integration tests that exercise the full prediction lifecycle: record predictions
during scan/recommendation → collect outcomes → score predictions → compute attribution.
Also verify cross-cutting concerns: performance (< 2s for 1,000 predictions), idempotent
scoring, cold start with zero data, and the never-raises contract across the entire flow.

## Acceptance Criteria

- [ ] Full lifecycle integration test: scan → recommend → persist → collect → score → attribute
- [ ] Cold start test: zero predictions → attribution returns empty report, no crash
- [ ] Idempotent scoring test: scoring same predictions twice produces same result
- [ ] Performance test: attribution computes in < 2s for 1,000 predictions
- [ ] Never-raises test: DB error during scoring → logged, not propagated
- [ ] All tests pass with `uv run pytest tests/integration/test_prediction_lifecycle.py -v`
- [ ] At least one `@pytest.mark.critical` test

## Technical Details

- Integration tests use in-memory SQLite with all migrations applied
- Full lifecycle: create recommendations → save predictions → save outcomes → score → query → attribute
- Performance test: generate 1,000 factory predictions, time `compute_attribution()`
- Idempotent: score, change score, verify latest value sticks
- Cold start: fresh DB, call `compute_attribution([])` and `run_prediction_scoring(repo)`
