# Task: Enrich rule generation with condition dimensions

## Description

Expand `mine_patterns()` grouping to include ADX and ATR% condition buckets alongside
existing sector/IV/DTE/direction dimensions. Update `generate_rules()` to include
condition dimensions in `StrategyCondition` lists. This produces patterns like
"Trend desk 89% accurate when ADX > 25 and IV Rank < 30". Chi-squared significance
test enforced (p < 0.05) with minimum 20 samples per condition bucket.

## Acceptance Criteria

- [ ] `mine_patterns()` groups by `(sector, iv_bucket, dte_bucket, direction, adx_bucket, atr_bucket)` 6-tuple
- [ ] `generate_rules()` includes ADX and ATR% conditions in `StrategyCondition` list
- [ ] Condition dimensions with None values excluded from grouping (not a bucket)
- [ ] Chi-squared significance test still enforced on expanded dimensions
- [ ] Minimum 20 samples per cell enforced
- [ ] `render_learned_patterns()` naturally renders condition-enriched rules (no changes needed)
- [ ] Existing patterns without condition data still mine correctly

## Technical Details

- `mine_patterns()` at lines 142-190 currently groups by `(sector, iv_bucket, dte_bucket, direction)`
- Expand to 6-tuple: `(sector, iv_bucket, dte_bucket, direction, adx_bucket, atr_bucket)`
- For outcomes with `adx=None`, use `"unknown"` bucket or exclude from condition grouping
- Better approach: use optional classification — only include in condition groupings when data exists
- `generate_rules()` at lines 246-357 builds `StrategyCondition` list — add conditions for `adx_bucket` and `atr_bucket`
- `render_learned_patterns()` uses `rule.conditions` to build text — condition-enriched rules render naturally
