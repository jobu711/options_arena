# Task: Contract guidance computation and rendering

## Description

Create `learning/contract_guidance.py` — a new module that computes optimal delta and DTE
ranges from contract outcome data and renders them as a `<<<CONTRACT_GUIDANCE>>>` prompt
block. Returns `ContractGuidance` when >= 30 outcomes exist, or `None` when insufficient
data. Follows the `render_learned_patterns()` pattern from `strategy_book.py`.

## Acceptance Criteria

- [ ] `learning/contract_guidance.py` created as new module
- [ ] `compute_contract_guidance(outcomes) -> ContractGuidance | None` function
- [ ] `render_contract_guidance(guidance) -> str` function producing `<<<CONTRACT_GUIDANCE>>>` block
- [ ] Delta bucketing: 0.10 increments (0.10-0.20, 0.20-0.30, etc.)
- [ ] DTE bucketing: 15-day increments (0-15, 15-30, 30-45, etc.)
- [ ] Returns `None` when < 30 outcomes
- [ ] Returns range with highest win rate when sufficient data
- [ ] Prompt block respects max length (same pattern as `render_learned_patterns`)
- [ ] Unit tests pass

## Technical Details

- Delta values come from `recommended_contracts.delta` (absolute value, 0.0-1.0 range)
- DTE values come from `recommended_contracts.dte_at_entry` (computed from expiration - created_at)
- Win rate = `is_winner=True` / total per bucket
- Optimal range = bucket with highest win rate AND >= 30 samples
- If no bucket has >= 30 samples, return None
- Need to query outcomes with their recommended_contract data (delta, DTE)

### Edge Cases
- All outcomes in one delta bucket → that bucket is optimal (if >= 30)
- Tie in win rate between buckets → either is valid (deterministic sort)
- Delta = 0.0 or 1.0 (boundary values) → classified into first/last bucket
- Very large DTE (365+) → classified into last DTE bucket
