# Task: Weight tuner prediction-derived accuracy

## Description

Update `weight_tuner.py` to source per-desk accuracy from the `predictions` table instead
of the legacy `agent_predictions` table. Add `render_tuned_weights()` function for prompt
injection. Update the existing `outcomes auto-tune` / `outcomes agent-weights` CLI output
to show prediction-derived sample counts. Interface unchanged: `compute_auto_tune_weights()`
still takes `list[AgentAccuracyReport]`.

### Action
1. Add `render_tuned_weights(weights: VoteWeights) -> str` to `weight_tuner.py`:
   ```python
   def render_tuned_weights(weights: VoteWeights) -> str:
       lines = ["Current desk vote weights (auto-tuned from prediction accuracy):"]
       for agent, weight in sorted(weights.items()):
           lines.append(f"  {agent}: {weight:.2f}")
       return "\n".join(lines)
   ```
   - WHY: produces text for `SynthesisDeps.tuned_weights` field, injected into synthesis prompt
2. Add helper `_prediction_accuracy_to_agent_report(acc: PredictionAccuracy) -> AgentAccuracyReport`:
   - Map `PredictionSource.DESK_TREND` → agent_name `"trend"` (strip `desk_` prefix)
   - Map `acc.accuracy` → `direction_hit_rate`
   - Compute `brier_score` from accuracy: `brier = 1.0 - accuracy` (simplified approximation)
   - Set `mean_confidence = accuracy` (best available proxy)
   - WHY: bridge between new prediction model and existing weight computation interface
3. In `auto_tune_weights()`, try predictions first, fall back to legacy:
   ```python
   pred_accuracy = await repo.get_prediction_accuracy(window_days=window_days)
   desk_accuracy = [a for a in pred_accuracy if a.source.value.startswith("desk_")]
   if desk_accuracy and all(a.sample_sufficient for a in desk_accuracy):
       accuracy_reports = [_prediction_accuracy_to_agent_report(a) for a in desk_accuracy]
       data_source = "predictions"
   else:
       accuracy_reports = await repo.get_agent_accuracy(window_days=window_days)
       data_source = "legacy"
   ```
   - WHY: gradual migration — uses predictions when available, falls back gracefully
4. Update `outcomes agent-weights` CLI to show data source:
   - Add "Data source: predictions (N scored)" or "Data source: legacy agent_predictions"
   - WHY: user visibility into what's driving the weight proposals (US-3)
