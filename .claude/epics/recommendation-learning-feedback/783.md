# Task: Prompt injection for contract guidance and tuned weights

## Description

Wire contract guidance and tuned weights into the synthesis agent prompt. Add
`contract_guidance: str` field to `SynthesisDeps`, update the dynamic system prompt
to inject `<<<CONTRACT_GUIDANCE>>>`, and populate both `contract_guidance` and
`tuned_weights` in the recommendation orchestrator. Currently `tuned_weights` exists
on `SynthesisDeps` but is never populated — fix that too.

## Acceptance Criteria

- [ ] `SynthesisDeps.contract_guidance: str = ""` field added
- [ ] `_synthesis_system_prompt()` injects `<<<CONTRACT_GUIDANCE>>>` block when present
- [ ] Orchestrator populates `contract_guidance` from `fetch_contract_guidance(repo)`
- [ ] Orchestrator populates `tuned_weights` from `render_tuned_weights(current_weights)`
- [ ] All injection is never-raises (failures logged, synthesis continues without blocks)
- [ ] Synthesis prompt includes all 3 blocks when data exists: LEARNED_PATTERNS, TUNED_WEIGHTS, CONTRACT_GUIDANCE
- [ ] Unit tests pass

## Technical Details

- `SynthesisDeps` is in `agents/synthesis_agent.py` lines 35-45, already has `tuned_weights: str = ""`
- Dynamic prompt at lines 57-65 already injects `tuned_weights` and `learned_patterns`
- Add `contract_guidance` injection following the same pattern
- Orchestrator constructs `SynthesisDeps` at lines 640-646 — add new field population
- `fetch_contract_guidance()` from Task 781, `render_tuned_weights()` from Task 782
- All fetches wrapped in try/except (never-raises)
