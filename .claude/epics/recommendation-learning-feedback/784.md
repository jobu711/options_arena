# Task: Feedback loop integration tests

## Description

Write integration tests that exercise the full feedback loop: condition-enriched strategy
mining, contract guidance computation from outcomes, weight tuner with prediction-derived
accuracy, and prompt injection of all three blocks into the synthesis agent. Verify
backward compatibility of all changed modules and the cold-start scenario.

## Acceptance Criteria

- [ ] Strategy mining with condition dimensions produces enriched patterns
- [ ] Contract guidance returns `None` with insufficient data, valid guidance with sufficient data
- [ ] Weight tuner uses predictions when available, falls back to legacy when not
- [ ] Synthesis prompt contains all 3 injection blocks when data exists
- [ ] Cold start (zero data) → all functions return gracefully, no crash
- [ ] All existing tests in `tests/unit/learning/` still pass
- [ ] At least one `@pytest.mark.critical` test
- [ ] Performance: strategy mining with 500 enriched outcomes completes in < 5s

## Technical Details

- Integration tests use in-memory SQLite with full migrations
- Full loop: create outcomes with delta/DTE → compute contract guidance → verify block
- Strategy mining loop: create enriched outcomes → mine patterns → generate rules → render
- Weight tuner loop: create predictions → get accuracy → compute weights → render
- Cold start: empty DB → all functions return None/empty, synthesis runs without blocks
