# Task: Prediction models and enums

## Description

Create `models/attribution.py` with `PredictionSource` StrEnum and all 6 Pydantic models
needed by the prediction ledger: `Prediction`, `PredictionAccuracy`, `ConditionBucketAccuracy`,
`ContractGuidance`, `AttributionReport`. All models frozen with NaN/Inf defense on every
numeric field. Re-export from `models/__init__.py`.

## Acceptance Criteria

- [ ] `PredictionSource` StrEnum with 8 values (SCAN_DIRECTION, 6 desks, SYNTHESIS)
- [ ] `Prediction` frozen model with `isfinite()` + `[0.0, 1.0]` validator on `confidence`
- [ ] `Prediction` model_validator ensures at least one of `recommendation_id` or `scan_run_id` is set
- [ ] `PredictionAccuracy` frozen model with `isfinite()` guard on `accuracy`
- [ ] `ConditionBucketAccuracy` frozen model with `isfinite()` guard on `accuracy`
- [ ] `ContractGuidance` frozen model with `isfinite()` guards on all float fields
- [ ] `AttributionReport` frozen model aggregating the above
- [ ] All models re-exported from `models/__init__.py`
- [ ] Unit tests pass, ruff clean, mypy --strict clean

## Technical Details

- Follow exact model shapes from PRD `Architecture & Design > Data Models` section
- `PredictionSource` maps to desk names matching `DeskType` StrEnum values (but prefixed with `desk_`)
- No `DESK_RESEARCH` — Research desk is interactive, doesn't produce `DomainAssessment`
- Context snapshot fields (`adx`, `iv_rank`, `atr_pct`, `rsi`) are `float | None`
- `was_correct` is `bool | None` (None until scored)
- `created_at` is `datetime` with UTC validator
- `id` field defaults to `0` for pre-persistence (DB assigns actual id)

### Action
1. Create `src/options_arena/models/attribution.py` with module docstring
   - WHY: new module for prediction ledger models, follows existing `analytics.py` / `strategy.py` pattern
2. Add `PredictionSource(StrEnum)` with 8 values: `SCAN_DIRECTION`, `DESK_TREND`, `DESK_VOLATILITY`, `DESK_FLOW`, `DESK_FUNDAMENTAL`, `DESK_RISK`, `DESK_CONTRARIAN`, `SYNTHESIS`
   - WHY: maps 1:1 to scan pipeline + 6 recommendation desks + synthesis agent
3. Add `Prediction(BaseModel)` with `model_config = ConfigDict(frozen=True)`:
   - Fields: `id: int = 0`, `recommendation_id: int | None = None`, `scan_run_id: int | None = None`, `ticker: str`, `source: PredictionSource`, `predicted_direction: SignalDirection`, `confidence: float`, `adx: float | None = None`, `iv_rank: float | None = None`, `atr_pct: float | None = None`, `rsi: float | None = None`, `was_correct: bool | None = None`, `created_at: datetime`
   - `@field_validator("confidence")`: `isfinite()` then `0.0 <= v <= 1.0`
   - `@field_validator("created_at")`: UTC validator (reject naive, reject non-UTC)
   - `@model_validator(mode="after")`: ensure `recommendation_id is not None or scan_run_id is not None`
   - Optional float context fields: `@field_validator("adx", "iv_rank", "atr_pct", "rsi")`: if not None, must be `isfinite()`
   - WHY: frozen snapshot, NaN defense required by CLAUDE.md, dual FK validated at model level
4. Add `PredictionAccuracy(BaseModel, frozen=True)`: `source`, `total: int`, `correct: int`, `accuracy: float`, `sample_sufficient: bool`
   - Validators: `isfinite()` on `accuracy`, `total >= 0`, `correct >= 0`
   - WHY: per-source accuracy stats for attribution report
5. Add `ConditionBucketAccuracy(BaseModel, frozen=True)`: `source`, `condition: str`, `total: int`, `correct: int`, `accuracy: float`
   - WHY: accuracy sliced by ADX/IV Rank bucket
6. Add `ContractGuidance(BaseModel, frozen=True)`: `optimal_delta_low: float`, `optimal_delta_high: float`, `optimal_dte_low: int`, `optimal_dte_high: int`, `delta_win_rate: float`, `dte_win_rate: float`, `sample_count: int`
   - All float fields: `isfinite()` guard, win rates `[0.0, 1.0]`
   - WHY: learned contract parameters for synthesis prompt injection
7. Add `AttributionReport(BaseModel, frozen=True)`: `window_days: int`, `total_recommendations: int`, `total_outcomes: int`, `source_accuracy: list[PredictionAccuracy]`, `condition_accuracy: list[ConditionBucketAccuracy]`, `contract_guidance: ContractGuidance | None`
   - WHY: top-level report aggregating all attribution data
8. Update `src/options_arena/models/__init__.py` — add re-exports for all new models and `PredictionSource`
   - WHY: standard pattern, all models importable from `options_arena.models`
