# Task: Offline Regime Classifier Training Script

## Description
Create `tools/train_regime_classifier.py` — an offline training script that trains a Gradient Boosting classifier on historical scan data to classify market regimes. The feature vector is built from Phase 2 indicators (RSI, ADX, ATR/price, volume ratio, IV rank, IV-HV spread, put-call ratio, Bollinger %B, MACD histogram). Labels: trending-up, trending-down, mean-reverting, high-volatility, low-volatility. Saves trained model to `data/model_cache/regime_classifier.pkl` via `joblib`.

This is the foundation task — B2 (ML inference in pipeline) depends on the model artifact produced here.

## Acceptance Criteria
- [ ] GBM classifier (`GradientBoostingClassifier`) with configurable hyperparameters (n_estimators, max_depth, learning_rate)
- [ ] Feature extraction function from historical `IndicatorSignals` (9 features: RSI, ADX, ATR%, relative_volume, IV rank, IV-HV spread, put_call_ratio, BB width, MACD)
- [ ] 5-class labels: `trending_up`, `trending_down`, `mean_reverting`, `high_volatility`, `low_volatility`
- [ ] Cross-validation with `classification_report` output
- [ ] Model serialization to `data/model_cache/` via `joblib.dump`/`joblib.load` (top-level `import joblib`, NOT `sklearn.externals`)
- [ ] Guarded scikit-learn import with clear error message when not installed
- [ ] `data/model_cache/` directory created if missing; path is gitignored
- [ ] Script runnable as `python tools/train_regime_classifier.py --help` with argparse CLI

## Technical Details
- **New file**: `tools/train_regime_classifier.py`
- scikit-learn >=1.5 (already in `[ml]` optional extra group from Epic A planning)
- Feature vector uses raw indicator values (not normalized 0-100), extracted from `IndicatorSignals` fields
- Labels derived from heuristic rules on historical data (ADX + ROC + ATR% + RSI thresholds)
- The script is offline tooling, not part of the scan pipeline runtime
- Uses `argparse` (not typer) since this is a standalone tool
- `joblib` is a dependency of scikit-learn — no separate install needed
