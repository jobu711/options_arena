# Task: Contract Greeks Clustering

## Description
Implement `cluster_contracts_by_greeks()` in a new `scoring/clustering.py` module using K-means on normalized (delta, gamma, theta, vega) vectors. Assign semantic cluster labels via centroid analysis ("high-gamma", "income", "vol-play", "directional"). Integrate into `scoring/contracts.py` after Greeks computation for debate context enrichment. Config-gated via `MLConfig.enable_clustering: bool = False`.

## Acceptance Criteria
- [ ] New file `scoring/clustering.py` with `cluster_contracts_by_greeks()` function
- [ ] K-means clustering on min-max normalized Greeks vectors (delta, gamma, theta, vega)
- [ ] Semantic cluster labels: "high-gamma", "income", "vol-play", "directional" assigned by centroid analysis
- [ ] Returns `ClusteringResult` Pydantic model (scoring module convention: typed models, not dicts)
- [ ] Degrades gracefully: returns empty result when <10 contracts with valid Greeks
- [ ] Config flag `enable_clustering: bool = False` on `MLConfig`
- [ ] Guarded scikit-learn import (`_get_kmeans()` helper)
- [ ] Optional integration call in `scoring/contracts.py` after `compute_greeks()`

## Technical Details
- **New file**: `scoring/clustering.py`
- **Modified files**: `scoring/contracts.py`, `models/config.py`, `scoring/__init__.py`
- Scoring module convention: returns typed Pydantic model, imports `pricing/dispatch` only
- `ClusteringResult` model with `clusters: list[ContractCluster]` and `n_clusters: int`
- `ContractCluster` model with `label: str`, `contract_indices: list[int]`, `centroid: GreeksCentroid`
- `GreeksCentroid` model with `delta: float`, `gamma: float`, `theta: float`, `vega: float`
- Min-max normalization per Greeks dimension before clustering (sklearn `MinMaxScaler`)
- Centroid analysis for label assignment:
  - Highest |gamma| centroid → "high-gamma"
  - Most negative theta centroid → "income" (theta harvesters)
  - Highest vega centroid → "vol-play"
  - Highest |delta| centroid → "directional"
- Silhouette score stored in result for quality assessment
- K=4 default clusters (configurable via `MLConfig.contract_n_clusters`)
