# Task: Flow Anomaly Detection

## Description
Add `detect_flow_anomalies()` to `indicators/flow_analytics.py` using Isolation Forest for options flow anomaly detection. Features: volume/OI ratio, call/put volume ratio, volume vs 20d average, large trade concentration. Flags unusual patterns for Flow Agent context. Config-gated via `MLConfig.enable_flow_anomaly: bool = False`. Returns a NamedTuple (indicator module convention).

## Acceptance Criteria
- [ ] `detect_flow_anomalies()` function in `indicators/flow_analytics.py`
- [ ] Uses Isolation Forest on 4-feature flow matrix
- [ ] Returns `FlowAnomalyResult` NamedTuple with `anomaly_score: float`, `is_anomalous: bool`, `feature_contributions: dict[str, float]`
- [ ] Returns `None` when scikit-learn not installed or insufficient data (<20 rows)
- [ ] Config flag `enable_flow_anomaly: bool = False` on `MLConfig`
- [ ] `IndicatorSignals` gets new field `flow_anomaly_score: float | None = None`
- [ ] `MarketContext` gets new field `flow_anomaly_score: float | None = None`
- [ ] Agent context rendering in `agents/_parsing.py` includes flow anomaly in Flow Agent block

## Technical Details
- **Modified files**: `indicators/flow_analytics.py`, `models/config.py`, `models/scan.py`, `models/analysis.py`, `agents/_parsing.py`, `scan/phase_scoring.py`
- Indicator module convention: NamedTuple return, pandas/numpy input, no Pydantic models, no API calls
- Feature matrix (per-strike row):
  1. `volume / open_interest` ratio (capped at 10.0 to reduce outlier impact)
  2. Call volume / Put volume ratio (log-transformed)
  3. Volume / 20-day average volume ratio
  4. Large trade concentration: % of volume in top 5 strikes
- Isolation Forest with `contamination=0.1` (10% anomaly rate), `n_estimators=100`, `random_state=42`
- `anomaly_score` is the sklearn `decision_function` score (negative = more anomalous)
- `is_anomalous` = True when score < 0 (sklearn convention)
- `feature_contributions` approximated by per-feature z-scores of the aggregated row vs population
