# Task: Neural Surface Pipeline Integration

## Description
Integrate the neural IV surface as an alternative fitter in `compute_vol_surface()`. Add config flag `surface_method: Literal["spline", "neural"]` to select between spline (default) and neural surface fitting. Automatic fallback to spline when: <30 data points, Lightning not installed, training timeout, or neural fit failure. Wire into `scan/phase_options.py` so the pipeline calls the neural surface when configured.

## Acceptance Criteria
- [ ] `surface_method` config selects spline vs neural in `compute_vol_surface()`
- [ ] Automatic fallback to spline on any neural failure
- [ ] Neural surface results compatible with `VolSurfaceResult` NamedTuple
- [ ] Pipeline integration in `phase_options.py` gated by `ml.enable_neural_surface` config flag
- [ ] Default config behavior identical to current (spline only)
- [ ] Existing vol surface tests pass unchanged

## Technical Details
- `indicators/vol_surface.py` — add neural fitting path inside `compute_vol_surface()`
- `scan/phase_options.py` — pass `surface_method` from config to `compute_vol_surface()`
- Neural surface uses `fit_neural_surface()` from `pricing/neural_surface.py`
- Translation layer: convert `NeuralSurfaceResult` fields into `VolSurfaceResult` format
- Fallback chain: neural attempt -> spline attempt -> standalone fallback -> None result
- No new dependencies — uses `pricing/neural_surface.py` from Task 001

### Action
1. In `indicators/vol_surface.py`, modify `compute_vol_surface()`:
   - Add `surface_method: str = "spline"` parameter (default preserves existing behavior)
   - When `surface_method == "neural"` and data >= 30 points:
     - Import `fit_neural_surface` from `pricing/neural_surface` via guarded import
     - Call `fit_neural_surface(strikes, ivs, dtes, spot, config)`
     - If result is not None, translate `NeuralSurfaceResult` -> `VolSurfaceResult`
     - Preserve skew_25d, smile_curvature, prob_above_current from standalone methods
     - Set `is_standalone_fallback=False`, `is_1d_fallback=False`
   - On any neural failure: fall through to existing spline path (log at DEBUG)
   - WHY: minimal invasive change, fallback chain preserves reliability

2. In `scan/phase_options.py`, pass surface method through:
   - Extract `surface_method` from `scan_config.ml.surface_method`
   - Pass to `compute_vol_surface(... surface_method=surface_method)` call
   - Only pass `"neural"` when both `ml.enable_neural_surface` AND `surface_method == "neural"`
   - WHY: double-gating ensures neural surface only activates when explicitly configured

3. Add `surface_method` parameter to the `compute_vol_surface()` docstring
   - WHY: document the new parameter for indicator module conventions
