# Task: Trajectory Integration + Agent Enrichment

## Description
Wire both neural models (IV surface and trajectory) into the scan pipeline and agent prompts. `prob_profit_neural` is available to all agents as a supplementary probability estimate via `MarketContext`. Render neural probability and surface comparison in `agents/_parsing.py`. Enrich the Volatility Agent with neural surface residuals context (spline vs neural R-squared comparison). All features are no-op when config flags are False or when neural dependencies are missing.

## Acceptance Criteria
- [ ] `prob_profit_neural` rendered in agent context when available (via `_parsing.py`)
- [ ] Volatility Agent receives neural surface vs spline comparison context
- [ ] Config flag `enable_trajectory: bool = False` gates trajectory pipeline integration
- [ ] All features no-op when config flags are False
- [ ] Existing tests pass with default config (all neural features off)
- [ ] Pipeline calls trajectory model in Phase 3 when enabled
- [ ] Neural context rendering uses `_render_optional()` pattern with `math.isfinite()` guards

## Technical Details
- `agents/_parsing.py` — add neural context rendering functions
- `agents/volatility.py` — extend system prompt with neural surface context
- `scan/phase_options.py` — wire trajectory model call + populate `prob_profit_neural` on `MarketContext`
- Rendering pattern: `_render_optional("Neural P(profit)", ctx.prob_profit_neural, ".1%")`
- Volatility Agent context: compare surface_fit_r2 (spline) vs neural R-squared when both available
- String concatenation (NOT `str.format()`) for LLM-safe prompt assembly
- Trajectory model called after chain fetch (needs spot price and strike from recommended contract)
- `asyncio.to_thread()` + `wait_for(timeout=5.0)` wrapping synchronous torch inference

### Action
1. In `agents/_parsing.py`, add neural context rendering:
   - Add `_render_neural_context(ctx: MarketContext) -> str` function:
     - Renders `prob_profit_neural` when available
     - Uses `_render_optional()` pattern with `math.isfinite()` guard
     - Returns empty string when no neural data available
   - Add `_render_neural_surface_comparison(ctx: MarketContext) -> str` function:
     - Compares `surface_fit_r2` (spline) with neural surface R-squared if available
     - Renders which method has better fit quality
     - Returns empty string when neural surface not used
   - WHY: follows existing rendering pattern (additive context, string concat)

2. In `agents/_parsing.py`, extend `render_context_block()`:
   - Append `_render_neural_context(ctx)` to context block output
   - WHY: all agents see neural probability when available

3. In `agents/volatility.py`, extend volatility-specific context:
   - Append neural surface comparison section to volatility agent prompt
   - Call `_render_neural_surface_comparison(ctx)` from parsing module
   - Use string concatenation (NOT `str.format()`) for LLM text safety
   - WHY: volatility agent is the natural consumer of surface quality metrics

4. In `scan/phase_options.py`, wire trajectory model:
   - After chain fetch and contract recommendation (spot + strike available):
     - If `scan_config.ml.enable_trajectory` is True:
       - Build feature sequence from OHLCV data (last 60 bars)
       - Call `fit_trajectory_model()` via `asyncio.to_thread()` + `wait_for(timeout=5.0)`
       - Call `compute_prob_profit()` with forecasts, spot, and strike
       - Set `ticker_score.signals.prob_profit_neural` or propagate to `MarketContext`
     - On any failure: log at DEBUG, leave field as None
   - WHY: trajectory needs spot price and recommended contract strike

5. In `scan/phase_options.py`, ensure `prob_profit_neural` propagates to `MarketContext`:
   - In `build_market_context()` (orchestrator.py) or wherever MarketContext is assembled
   - Map from scoring/pipeline result to MarketContext field
   - WHY: agents consume MarketContext, not raw pipeline internals

### Edge Cases
- `prob_profit_neural` = 0.0: renders as "0.0%" (valid edge)
- `prob_profit_neural` = 1.0: renders as "100.0%" (valid edge)
- Neural surface not available but trajectory is: only trajectory context renders
- Both neural models fail: all neural context empty, pipeline continues normally
- OHLCV data < 60 bars: trajectory skipped (insufficient sequence length)
- No recommended contract (0 contracts): trajectory skipped (no strike for prob computation)
