# Task: Verify spec-analyzer taxonomy output on existing PRD

## Description

Run the enhanced spec-analyzer agent on an existing PRD (unified-agent-system or another
substantial PRD) to verify the 11-category taxonomy, Impact x Uncertainty scoring, and
enhanced question format work correctly. This is a validation task — no files are modified,
only the output is inspected.

## Acceptance Criteria

- [ ] spec-analyzer runs successfully on at least one existing PRD
- [ ] Output includes 11-category taxonomy coverage table
- [ ] Each category row shows scan status and gap count
- [ ] Gaps have Impact (1-3) and Uncertainty (1-3) scores
- [ ] Priority = Impact x Uncertainty, questions sorted descending
- [ ] Maximum 5 prioritized questions in output (additional gaps in coverage table only)
- [ ] Question format includes all 6 fields: classification, score, category, context, recommended, impact
- [ ] Empty categories show "0 gaps" (not omitted)
- [ ] Output is well-formatted markdown

## Technical Details

### Target PRD

Run spec-analyzer on `.claude/prds/unified-agent-system.md` — this is the largest and most
complex PRD, providing the best test of taxonomy coverage. If that PRD is unavailable, use
any PRD with substantive content (not the spec-kit-workflow-patterns PRD itself, as that
would be circular).

### What to Inspect

1. **Taxonomy coverage table**: All 11 categories present, each with gap count
2. **Scored gaps**: Each gap has Impact and Uncertainty scores
3. **Question ranking**: Top 5 by Priority (Impact x Uncertainty), descending
4. **Question format**: Each has Category, Context, Recommended, Alternatives, Impact if unanswered
5. **Backward compatibility**: Phases 1, 2, 4 still produce expected output

### Expected Behavior

The spec-analyzer should:
- Scan the PRD through all 11 categories
- Find gaps in multiple categories (a complex PRD should have gaps)
- Score each gap
- Surface the top 5 as prioritized questions with full format
- Show remaining gaps in the taxonomy coverage table
