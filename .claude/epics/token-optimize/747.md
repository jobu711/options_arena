# Task: Baseline Measurement

## Description
Measure current auto-loaded context size and estimate per-session token usage before any
changes. This establishes the baseline against which all improvements are measured.

## Acceptance Criteria
- [ ] Auto-loaded line count documented (CLAUDE.md + @-referenced files + rules)
- [ ] Per-file line counts recorded for all context files
- [ ] Module CLAUDE.md line counts recorded (all 14 files)
- [ ] Agent definition line counts recorded (all 19 files)
- [ ] Baseline saved to .claude/epics/token-optimize/baseline.md

## Technical Details
- Count lines: `wc -l CLAUDE.md .claude/context/*.md .claude/rules/*.md`
- Count module files: `find src/options_arena -name "CLAUDE.md" -exec wc -l {} +`
- Count agent defs: `wc -l .claude/agents/*.md`
- Count prompts: `find .claude/prompts -name "*.md" -exec wc -l {} +`
- Estimate token overhead: lines × ~4 tokens/line (rough estimate)
