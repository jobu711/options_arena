## Technical Details

Compression strategy per file:
1. **Remove file-by-file listings** — every module CLAUDE.md lists every .py file with
   descriptions. Claude can Glob for these. Replace with "use Glob to discover files."
2. **Remove import examples** — `from options_arena.models import X` examples. Claude reads code.
3. **Remove pattern code blocks** — Pydantic patterns, async patterns, etc. already in Tier 0/1.
4. **Remove re-export listings** — `__init__.py` re-exports listed verbatim. Claude reads __init__.py.
5. **Keep critical constraints** — gotchas, boundary rules, field mappings, non-obvious behavior.
6. **Keep "What Claude Gets Wrong"** — these prevent recurring errors.

Priority: constraints > gotchas > field mappings > examples > listings.
