# Task: Audit and Trim Agent Definitions + Stale Prompts

## Description
Audit 19 agent definition files in `.claude/agents/` for usage, redundancy, and verbosity.
Compress remaining agent descriptions. Audit 28 prompt files in `.claude/prompts/` for
staleness (references to deleted debate system, unused features). Remove stale files.

This task is independent of the Tier 0/1/2 restructuring.

## Acceptance Criteria
- [ ] Each agent definition audited for usage frequency
- [ ] Unused/redundant agents identified and removed
- [ ] Remaining agent descriptions compressed (verbose → 2-3 line summaries)
- [ ] Stale prompt files identified and removed
- [ ] PRD/epic workflow skills preserved (pm:* commands untouched)
- [ ] Total agent definition lines reduced by >= 30%

## Technical Details

**Agent definition audit** (19 files, ~4,054 lines with guides):
Current agents: multi-agent-coordinator, parallel-worker, quant-analyst, research-analyst,
prompt-engineer, risk-manager, tdd-orchestrator, test-runner, learnings-researcher,
spec-analyzer, bug-auditor, dep-auditor, code-reviewer, oa-python-reviewer,
security-auditor, architect-reviewer, code-analyzer, db-auditor, file-analyzer

Audit criteria per agent:
- Is it referenced in skills or frequently invoked? → Keep
- Does it duplicate another agent's capability? → Merge or remove
- Is the description >50 lines? → Compress to 20-30 lines

**Prompt audit** (28 files in .claude/prompts/):
- Check each prompt for references to deleted features (old debate agents, orchestrator.py)
- Check for prompts that haven't been used since major refactors
- Remove stale prompts, keep active ones

**Skills audit**:
- Review registered skills list for redundancy
- PRD/epic workflow (pm:*) preserved — constraint
- brainstorming, bug, code-rabbit, compound, context7, dead-code, fix-loop, full-audit,
  math-audit, prompt, re-init, release-prep, simplify, loop: evaluate each
- testing:*, frontend-design:*, context:*: evaluate each group
