# Task: Rewrite CLI debate command for run_recommendation()

## Description

Rewrite the CLI `debate` command in `cli/commands.py` to use `run_recommendation()` instead of `run_debate()`. Replace agent panel rendering with domain assessment panels + position recommendation display. Batch mode iterates with `run_recommendation()`. Export uses updated `export_recommendation_markdown()`. The `--fallback-only` flag is preserved.

## Acceptance Criteria

- [ ] `options-arena debate AAPL` calls `run_recommendation()` and renders result
- [ ] Domain assessments rendered as Rich panels (desk name, direction, confidence, summary)
- [ ] Position recommendation rendered: contract, entry/exit prices, sizing, risk/reward
- [ ] `--batch` mode works with `run_recommendation()` per ticker
- [ ] `--export md` uses `export_recommendation_markdown()`
- [ ] `--fallback-only` forces data-driven fallback (preserved behavior)
- [ ] `--provider` flag works (Groq/Anthropic dispatch unchanged)
- [ ] `--history` flag shows recommendation history (if applicable)
- [ ] Progress bar shows desk execution progress
- [ ] Service lifecycle: create all → use → close in finally

## Technical Details

### CLI Command Changes (`cli/commands.py`)

**`_debate_async()` rewrite**:
- Replace `run_debate(...)` call with `run_recommendation(...)`
- `run_recommendation()` returns `RecommendationResult`
- New rendering: assessments panels + recommendation table
- Decision gate: `should_recommend()` replaces `should_debate()`

**Rendering changes**:
- Current: Bull panel, Bear panel, Thesis panel, Risk panel, etc.
- New: 6 assessment panels (Trend, Volatility, Flow, Fundamental, Risk, Contrarian) + Recommendation panel
- Each assessment: desk name header, direction badge, confidence bar, key findings
- Recommendation: contract symbol, strike, expiration, entry/exit prices, position size %, risk/reward ratio
- Fallback badge when `is_fallback=True` with `confidence` shown

**`_batch_async()` rewrite**:
- Same sequential iteration pattern
- Replace `run_debate()` with `run_recommendation()` per ticker
- Per-ticker error isolation preserved (catch Exception, log, continue)

**Export**:
- `--export md`: `export_recommendation_markdown(result)` from reporting module
- PDF: same weasyprint wrapper if applicable
