## Technical Details
- Files: `src/options_arena/agents/prompts/recommend_{trend,volatility,flow,fundamental,risk,contrarian}.py`
- Each file imports `PROMPT_RULES_APPENDIX` from `options_arena.agents._parsing`
- Pattern: `RECOMMEND_TREND_PROMPT = """...\n\n""" + PROMPT_RULES_APPENDIX`
- Recommendation prompts differ from desk prompts: they use `PROMPT_RULES_APPENDIX`, focus on structured output fields
- Each prompt must reference the domain-specific optional fields of its Assessment subclass:
  - Trend: `trend_strength`, `momentum_signal`
  - Volatility: `iv_regime`, `vol_skew_assessment`, `term_structure_shape`
  - Flow: `flow_bias`, `unusual_activity_noted`
  - Fundamental: `valuation_signal`, `catalyst_timeline`
  - Risk: `max_position_pct`, `hedging_suggestion`, `portfolio_correlation_note`
  - Contrarian: `consensus_challenged`, `contrarian_thesis`
