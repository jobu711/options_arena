# Task: Trend + Volatility desk recommendation agents

## Description
Add recommendation mode to `trend_desk.py` and `volatility_desk.py`. Each file gains a second `Agent[DeskDeps, *Assessment]` instance that produces a structured `DomainAssessment` subclass. Existing interactive `Agent[DeskDeps, str]` instances are completely untouched. Add `run_*_desk_recommendation()` runner functions.

## Acceptance Criteria
- [ ] `trend_desk.py` has `trend_desk_recommend: Agent[DeskDeps, TrendAssessment]` instance
- [ ] `trend_desk.py` has `run_trend_desk_recommendation()` async runner (never raises)
- [ ] `volatility_desk.py` has `vol_desk_recommend: Agent[DeskDeps, VolatilityAssessment]` instance
- [ ] `volatility_desk.py` has `run_vol_desk_recommendation()` async runner (never raises)
- [ ] Both agents use `model=None` at init, `retries=2`
- [ ] Both agents share same toolset as interactive agent (via `build_*_toolset()`)
- [ ] Both agents have `@system_prompt(dynamic=True)` for learned patterns
- [ ] Both agents have `@output_validator` using `build_cleaned_domain_assessment()`
- [ ] Existing interactive desk agents completely unchanged
- [ ] Unit tests for both recommendation agents

## Technical Details
- Files: `src/options_arena/agents/trend_desk.py`, `src/options_arena/agents/volatility_desk.py`
- Pattern: add a second `Agent` instance alongside existing one, sharing same toolset
- Runner follows `run_*_desk_query()` pattern: never raises, `asyncio.wait_for` timeout, model=None guard
- Output type: `TrendAssessment` for trend, `VolatilityAssessment` for volatility
- On failure, return a fallback assessment with `confidence=0.2`, `direction=NEUTRAL`
- Prompt: import `RECOMMEND_TREND_PROMPT` / `RECOMMEND_VOLATILITY_PROMPT` from `prompts/`
- Runner signature:
  ```python
  async def run_trend_desk_recommendation(
      deps: DeskDeps,
      *,
      model: Model | None = None,
      model_settings: ModelSettings | None = None,
      config: AgencyConfig | None = None,
  ) -> TrendAssessment:
  ```
