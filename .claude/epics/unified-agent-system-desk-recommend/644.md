# Task: Flow + Fundamental desk recommendation agents

## Description
Add recommendation mode to `flow_desk.py` and `fundamental_desk.py`. Each file gains a second `Agent[DeskDeps, *Assessment]` instance that produces a structured `DomainAssessment` subclass. Existing interactive agents are completely untouched. Add `run_*_desk_recommendation()` runner functions.

## Acceptance Criteria
- [ ] `flow_desk.py` has `flow_desk_recommend: Agent[DeskDeps, FlowAssessment]` instance
- [ ] `flow_desk.py` has `run_flow_desk_recommendation()` async runner (never raises)
- [ ] `fundamental_desk.py` has `fundamental_desk_recommend: Agent[DeskDeps, FundamentalAssessment]` instance
- [ ] `fundamental_desk.py` has `run_fundamental_desk_recommendation()` async runner (never raises)
- [ ] Both agents use `model=None` at init, `retries=2`
- [ ] Both agents share same toolset as interactive agent
- [ ] Both agents have `@system_prompt(dynamic=True)` for learned patterns
- [ ] Both agents have `@output_validator` using `build_cleaned_domain_assessment()`
- [ ] Existing interactive desk agents completely unchanged
- [ ] Unit tests for both recommendation agents

## Technical Details
- Files: `src/options_arena/agents/flow_desk.py`, `src/options_arena/agents/fundamental_desk.py`
- Pattern identical to Task 643 -- only types and prompts differ
- Output types: `FlowAssessment` for flow, `FundamentalAssessment` for fundamental
- Prompts: `RECOMMEND_FLOW_PROMPT`, `RECOMMEND_FUNDAMENTAL_PROMPT`
- Fallback assessment: `confidence=0.2`, `direction=NEUTRAL`, desk-specific defaults
  - FlowAssessment fallback: `flow_bias=None`, `unusual_activity_noted=False`
  - FundamentalAssessment fallback: `valuation_signal=None`, `catalyst_timeline=None`
