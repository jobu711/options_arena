# Task: Synthesis agent system prompt

## Description

Create the synthesis agent's system prompt in `agents/prompts/synthesis.py`. This prompt instructs the synthesis agent to weigh 6 domain assessments and produce a `PositionRecommendation` with a specific contract, entry/exit criteria, position sizing, and risk assessment. Uses `PROMPT_RULES_APPENDIX` (like debate prompts, unlike desk prompts).

## Acceptance Criteria

- [ ] `SYNTHESIS_SYSTEM_PROMPT` constant in `agents/prompts/synthesis.py`
- [ ] Prompt < 8000 chars (project convention)
- [ ] Includes `PROMPT_RULES_APPENDIX` (confidence calibration, citation rules)
- [ ] Instructs agent to: weigh agreement/disagreement, select specific contract, define entry/exit, size position
- [ ] References `<<<TUNED_WEIGHTS>>>` and `<<<LEARNED_PATTERNS>>>` blocks for dynamic injection
- [ ] Does NOT contain dynamic data — all runtime injection stays in agent module

## Technical Details

- File: `src/options_arena/agents/prompts/synthesis.py`
- Pattern: follows debate prompt convention (`*_SYSTEM_PROMPT` + `PROMPT_RULES_APPENDIX`)
- Imports `PROMPT_RULES_APPENDIX` from `agents._parsing`
- The prompt must guide structured `PositionRecommendation` output

### Action

1. Create `src/options_arena/agents/prompts/synthesis.py`:
   - Import `PROMPT_RULES_APPENDIX` from `options_arena.agents._parsing`
   - Define `SYNTHESIS_SYSTEM_PROMPT` constant (concatenated with appendix)
   - WHY: separate prompt file per project convention — static only

2. Prompt content should instruct the synthesis agent to:
   - Receive 6 domain assessments (Trend, Vol, Flow, Fundamental, Risk, Contrarian)
   - Weigh agreement and disagreement across desks
   - Consider historical accuracy from `<<<TUNED_WEIGHTS>>>` block (advisory, not binding)
   - Consider learned patterns from `<<<LEARNED_PATTERNS>>>` block
   - Select the specific contract from available contracts
   - Define entry price (mid or limit), entry criteria, exit criteria
   - Set stop loss and take profit levels
   - Size the position using vol regime and desk agreement
   - Compute risk/reward ratio
   - Identify dissenting desks and explain the disagreement
   - WHY: synthesis replaces algorithmic verdict — needs clear instructions for structured output

3. Keep prompt under 8000 chars, focused on output structure requirements
   - WHY: project convention — prompts are concise, structured, not essays
