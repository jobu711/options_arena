# Task: Extract reusable functions from orchestrator.py to _context.py

## Description
Move 5 reusable functions from `orchestrator.py` to a new `agents/_context.py` module.
Update `orchestrator.py` with import-forwarding for backward compatibility (old imports
still work). The new recommendation orchestrator (Task 004) will import directly from
`_context.py`. Also add a `should_recommend()` alias for `should_debate()`.

## Acceptance Criteria
- [ ] New `agents/_context.py` module with 5 extracted functions + 1 alias
- [ ] `orchestrator.py` imports from `_context.py` and re-exports (backward compat)
- [ ] `agents/__init__.py` updated to import from `_context.py` where appropriate
- [ ] All existing tests still pass — zero behavior change
- [ ] `ruff check`, `mypy --strict` pass on both files
