### RecommendationMixin Methods

```python
class RecommendationMixin:
    async def save_recommendation(
        self, result: RecommendationResult, scan_run_id: int | None = None
    ) -> int:
        """Persist a RecommendationResult. Returns the DB row ID."""

    async def get_recommendation_by_id(self, rec_id: int) -> RecommendationRow | None:
        """Retrieve a single recommendation by ID."""

    async def get_recent_recommendations(self, limit: int = 20) -> list[RecommendationRow]:
        """Retrieve most recent recommendations, newest first."""

    async def get_recommendations_for_ticker(
        self, ticker: str, limit: int = 5
    ) -> list[RecommendationRow]:
        """Retrieve recommendations for a specific ticker, newest first."""
```

### Serialization

- `assessments_json`: Serialize `AnyAssessment` list via Pydantic's `model_dump_json()` on each
  assessment, collected into a JSON array string. Discriminator field `desk` enables round-trip.
- `key_factors_json`: `json.dumps(recommendation.key_factors)`
- `dissenting_desks_json`: `json.dumps([d.value for d in recommendation.dissenting_desks])`
- `entry_price`, `stop_loss`, `take_profit`: `str(Decimal)` for TEXT column storage

### Edge Cases
- `scan_run_id=None` (recommendation without a scan)
- Empty `dissenting_desks` list → `'[]'` in DB
- `stop_loss=None`, `take_profit=None` → SQL NULL
- `is_fallback=True` → stored as 1, read back as True
- Empty DB → `get_recent_recommendations()` returns `[]`
